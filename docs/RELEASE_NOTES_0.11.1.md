# CabinOS ONE 0.11.1 배포 준비

소스는 versionName 0.11.1 / versionCode 20입니다. **현재 apk/는 0.11.0 그대로입니다.**
아래 내용은 다음 Release용 초안이며 아직 배포된 변경으로 안내하지 않습니다.

## 변경 사항

- 이전 정차의 출발 마감·도보 왕복 예약을 실제 주행 전환 시 초기화합니다.
- 자연스러운 충전 잔여 시간 감소가 출발 음성을 반복하지 않도록 수정했습니다.
- 차량 권한 요청 이력을 저장하고, 같은 결과로 불필요하게 재연결하지 않습니다.
- Pleos 읽기 불가 capability는 30초 후 재확인합니다.
- 실제 SDK 좌석 점유·문·창문·공조·워셔액을 정차 중 제안에 활용합니다. 새 항목은 기기 검증 전입니다.
- 도착 시·분 선택, 집중 할 일 프리셋, 음성 서비스 미지원 시 명령 버튼을 제공합니다.
- 웹의 첫 사용 흐름을 정차·충전 중심으로 정리하고 주행·OSM 내비는 접힌 부가 데모로 이동했습니다.
- 속도 신호 분석 도구와 전체 시연 기록 도구를 추가했습니다. 대안 신선도 판정은 **꺼져 있습니다**.

## 사람이 완료할 배포 절차

1. KVM PC에서 [전체 시연](../scripts/demo/pleos-full-scenario.md)을 실행합니다. 실패 항목을 그대로 남깁니다.
2. 공식 SDK 포함 release를 팀 키로 서명합니다. 키·비밀번호는 저장소 밖에 둡니다.
3. 서명 APK를 `apk/퓨처랩스_CabinOS_ONE_release.apk`에 넣고 다음 명령으로 체크섬을 생성·확인합니다.

```bash
sha256sum "apk/퓨처랩스_CabinOS_ONE_release.apk" > apk/SHA256SUMS
sha256sum -c apk/SHA256SUMS
```

4. 같은 파일을 `adb install -r -g`로 설치하고 기기에서 가져온 base.apk 해시와 대조합니다.
5. 같은 APK의 실제 전체 시나리오 60~120초 연속 영상을 녹화합니다. **새 영상 링크: [실제 검증 후 입력]**.
6. 모든 시연 판정 통과 후 새 GitHub Release에 APK·체크섬·영상·검증 결과를 등록합니다.
   제목은 `CabinOS ONE 0.11.1`로 하고, 진단 영상을 전체 성공 영상으로 바꿔 표시하지 않습니다.
7. README 대표 영상, APK 버전, 제출 검토표의 해시를 새 검증 결과로 갱신합니다. 소스 링크는 병합 후 main 기준입니다.

이 작업에서는 APK 교체·새 서명·Release 게시를 수행하지 않았습니다.

표시등·TPMS는 capability 확인의 비공개 권한 요구로 제외했습니다. Tire의 Float API를 저압 Boolean으로 해석하지 않습니다.
