# 도로 안전시설 자료 검증·적용

확인일: 2026-10-25. 이 자료는 시설 **참고 위치**이며 상용 내비와 동등한 정확도를 검증한 데이터베이스가 아닙니다.

- 카메라는 [공식 목록](https://www.data.go.kr/data/15028200/standard.do)의 다운로드 JavaScript가 사용하는 공개 다운로드 경로로 21,882행씩 두 부분을 받았습니다. 합계가 목록의 43,764행과 일치하며 두 부분 간 동일한 전체 행은 0개입니다. 초기 503 실패 후 두 부분 모두 HTTP 200을 확인했습니다. 인증키를 사용하거나 5만 건 제한을 우회하지 않았습니다.
- 카메라 자료에는 속도 단속 외 다른 교통 단속시설도 포함되며, 이동식 카메라는 제외됩니다. 도로노선방향 1/2/3 코드를 나침반 방위각으로 바꾸지 않습니다.
- 기존 충남 단독 자료는 전국 방지턱 파일로 교체했습니다. 이전 파일을 단순 합산해서 중복 또는 오래된 위치를 다시 넣지 않았습니다.

## 처리 기준

| 처리 | 방지턱 | 카메라 |

방지턱 오류는 좌표 문제 3,077행, 미래 기준일 2,478행입니다. `2525년` 같은 날짜를 임의로 `2025년`으로 고치지 않았습니다. 같은 좌표·도로·설치장소·행정구역·속도가 일치할 때만 중복을 병합하고 **실제 기록 중 가장 최근 기준일**을 남깁니다. 설명이 충돌하면 임의의 한 위치를 골라 경고하지 않습니다.

변환본의 기준일 범위는 방지턱 2019-01-01~2026-08-27, 카메라 2021-09-24~2026-09-13입니다. 가져온 날인 2026-10-25로 기록 날짜를 덮어쓰지 않습니다. 날짜가 없는 전국 행, 잘못된 좌표, 삭제 또는 해석 불가능한 갱신 상태도 허용하지 않습니다. 이전 지역 자료처럼 기준일 열 자체가 없는 파일은 명시적으로 지정한 파일 기준일을 사용합니다.

관리기관 연락처·원본 전체 행은 APK·저장소에 넣지 않습니다. 식별 해시, 종류, 좌표, 도로명, 기준일, 제공된 유효 숫자 제한속도만 저장합니다. 제한속도 0이나 빈 값을 0km/h 제한으로 안내하지 않습니다.

## 앱에서의 사용

APK에 오프라인으로 포함합니다. 파일은 백그라운드에서 한 행씩 읽고 날짜 해석을 캐시합니다. 거대한 JSON 객체를 만들거나 전체 파일을 두 번 해석하지 않습니다. 좌표 격자를 사용해 인접 위치만 조회하고 최대 600m 안의 32개 참고 위치를 지도에 표시합니다.

- 오차 20m 초과, 10초를 넘긴 GPS, 백그라운드에서는 참고 위치를 표시하지 않습니다.
- 항목 기준일부터 365일이 지나면 표시·음성 후보에서 제외합니다. 위 표의 유효 수는 검사일 기준이며 시간이 지나면 감소합니다.
- 방지턱 참고 음성은 안내 활성·위치/방향 신뢰 가능·경로 이탈 아님·이동 속도 확인 조건에서만 제공합니다. 경로 선과 12m 이내, 앞으로 40~250m의 등록 위치를 후보로 하며 교차 경로가 모호하면 제외합니다.
- 회전 안내 150m 이내, 다른 음성 재생 중, 음성 입력 중에는 시설 음성을 내보내지 않습니다. 지점당 한 번, 지점 사이 최소 15초 간격입니다. 한국어 또는 영어로 ‘약 100미터 앞 경로 주변에 과속방지턱 등록 지점이 있습니다. 현장 표지를 확인하세요’라는 참고 안내를 사용합니다.
- 카메라도 같은 GPS·경로 조건에서 앞으로 40~500m의 거리 포함 참고 음성을 제공합니다. 적용 방향·차선을 검증하지 않았으므로 “경로 주변 등록 지점”으로 안내하며 현장 표지 확인을 요청합니다. 현재 차로의 제한 속도·단속 적용 여부는 단정하지 않습니다.
- 원본의 구간 위치 설명과 코드·길이가 일치하는 경우만 구간단속 시작·종료 지점을 구분합니다. 불명확한 시작·종료 정보는 추측하지 않습니다. 제한 속도 정보가 없거나 분류가 충돌하는 카메라는 음성에서 제외합니다. 구간 짝 연결·평균 속도 계산·실제 단속 종료 판정은 제공하지 않습니다.
- 화면 표시 32개 제한과 별도로 음성 후보를 검색합니다. 이미 안내한 지점 때문에 다음 시설의 안내가 막히지 않도록 선택합니다.
- 등록되지 않은 곳을 시설 없는 도로로 간주하지 않습니다. 반대편 도로·고가/지하·차선 단위 오경보 및 실제 시설 누락률을 현장에서 검증한 것은 아닙니다.

## 변환 재현

```sh
python -m unittest discover -s scripts/tests -p test_prepare_road_safety.py
python scripts/prepare_road_safety.py /path/to/과속방지턱정보.zip \
  app/src/main/assets/road_safety/national-bumps.json \
  --kind bump --as-of 2026-10-25 \
  --source-url https://www.data.go.kr/data/15028195/standard.do \
  --coverage '전국 제공자료 · 수록 누락 가능'
```

카메라 원본을 다시 받으려면 `python scripts/download_camera_data.py /path/outside-checkout/cameras`를 실행합니다. 원본에는 기관 연락처가 있으므로 저장소 밖에 보관합니다. 2분할 건수·겹침을 검사하고 5만 건을 초과하면 공식 Open API를 사용하도록 중단합니다.

단일 CSV/JSON을 담은 ZIP, UTF-8/CP949 CSV, 공식 `records` JSON을 지원합니다. ZIP 경로를 디스크에 풀지 않습니다. 여러 데이터 파일이 있는 ZIP은 임의로 하나를 고르지 않고 거절합니다. WGS84 열이 없고 투영좌표만 있는 파일은 좌표계를 추측하지 않습니다. 카메라 JSON은 같은 변환기에 `--kind camera`로 입력합니다.

## 상용 내비와의 정확도

**동등성을 입증하지 못했습니다.** 데이터 형식·중복 검사 및 경로 참고 로직의 자동 테스트를 실제 도로의 정답률로 표현하지 않습니다. 카카오맵·네이버맵·티맵의 동일 시간대 안내 결과, 현장 시설·방향·표지, 시간 동기화된 실기기 GPS를 대조한 누락률·오경보율·안내 시점 측정이 없으므로 정확도 백분율을 산출하지 않습니다. 현재 자료만으로 상용 내비 대체가 가능하다고 판단하지 않습니다.
