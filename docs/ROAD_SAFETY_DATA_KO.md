## APK에 반영한 충남 자료

- 원본 16,251행, 위경도 범위 검사 탈락 0행.
- 동일 위치·도로·설치장소·자료일·속도가 같은 중복 6,549행 병합.
- 같은 좌표에 다른 시설 설명이 붙은 388행은 제외. 한 좌표를 13개 도로가 공유하는 사례가 있으므로 임의의 한 도로를 고르지 않음.
- 결과 9,314개 좌표. 관리기관 연락처·원본 행 전체는 APK나 저장소에 넣지 않음.
- 좌표 검사를 통과했다는 것은 현장 위치가 정확하다는 뜻이 아님. 원본의 주소·시설 폐지·새 시설 누락은 별도 검증이 필요함.
- 자료일은 파일 기준 2025-11-13이며 내려받은 날로 새것처럼 바꾸지 않음. 앱은 자료일로부터 365일이 지나면 해당 위치 표시·음성 참고 안내를 중단함. 최신 전국 파일 확보 후 교체 필요.

## 동작 및 제한

자료는 앱에 압축해 포함하며 네트워크나 공급자 인증키 없이 읽습니다. 초기 읽기는 IO 작업에서 수행하고, 인접 격자만 조회합니다. 최대 600m 안의 32개 위치를 지도에 참고 표시합니다. 오래되거나 오차 20m를 넘는 GPS, 백그라운드에서는 표시하지 않습니다.

방지턱 참고 음성은 주행 안내 활성·정확한 최신 GPS·방향 신뢰 가능·경로 이탈 아님·이동 속도 확인 조건에서만 사용합니다. 경로 선과 12m 이내이며 앞으로 40~250m에 있는 등록 위치만 후보로 삼고, 교차 경로가 모호하면 제외합니다. 회전 안내 150m 이내, 다른 음성 재생 중, 음성 입력 중에는 방지턱 음성을 내보내지 않습니다. 지점당 한 번, 지점 간 최소 15초 간격입니다. 한국어 또는 영어 참고 문구를 사용하며 제한속도를 단정하지 않습니다.

반대편 도로·고가/지하·차선 단위 구분을 완전히 검증한 시스템은 아닙니다. 음성은 ‘경로 주변에 과속방지턱 **등록 지점**이 있습니다. 현장 표지를 확인하세요’라는 참고 안내입니다. 위치 기록이 없는 곳을 시설 없는 도로라고 간주하지 않습니다.

카메라 데이터는 아직 미연결입니다. 데이터 형식과 지도 참고 위치 처리는 준비했지만, 공개 자료의 도로노선방향 코드가 곧바로 나침반 방향은 아니므로 이 값을 방위각으로 바꾸지 않습니다. 카메라 단속 적용 방향·구간단속 경고·현재 도로 제한속도 음성은 제공하지 않습니다. 전국 파일 첨부 후에도 방향 정보의 해석과 경로 연결 검증이 별도로 필요합니다.

## 변환 재현

```sh
python -m unittest discover -s scripts/tests -p test_prepare_road_safety.py
python scripts/prepare_road_safety.py /path/to/official.csv \
  app/src/main/assets/road_safety/chungnam-bumps.json \
  --kind bump --as-of 2025-11-13 \
  --source-url https://www.data.go.kr/data/15152204/fileData.do \
  --coverage '충청남도 12개 시군 · 전국 자료 아님'
```

UTF-8/CP949 CSV 및 공식 `records` JSON을 지원합니다. 위도·경도 열이 없는 투영좌표 파일은 자동으로 추측하지 않고 거절합니다. 전국 EPSG:5174 원본을 받으면 헤더·좌표계를 확인하고 검증된 WGS84 변환을 추가해야 합니다. 출력에는 원본 SHA-256, 출처, 자료일, 적용 범위, 처리 통계가 들어 있습니다.

처리 통계와 원본·변환본 해시는 [자료 검사 기록](ROAD_SAFETY_DATA_AUDIT.json)에 있습니다.

## 상용 내비와 동등한가?

**동등성을 입증하지 못했습니다.** 공개자료 내부 중복·좌표 형식과 앱 로직을 검사한 결과를 실제 도로의 정답률이나 카카오맵·네이버맵·티맵 대비 정확도로 표시하지 않습니다. 동일 출발지·목적지·시간대의 상용 내비 결과, 현장 시설·방향·속도 표지, 시간 동기화된 실기기 GPS를 대조한 누락률·오경보율·안내 시점 측정이 없으므로 정확도 백분율을 산출하지 않습니다. 현재 검사 결과로 실제 주행용 상용 내비 대체가 가능하다고 판단하지 않습니다.
