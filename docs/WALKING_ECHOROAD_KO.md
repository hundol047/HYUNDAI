# 보행 계획과 EchoRoad — 구현·검증 범위

2026-10-26, 퓨처랩스. Android 소스 및 휴대폰 검토판에 적용합니다. 차량 앱의 정차 전용 정책, 속도 0 + P 1.5초 확인과 신호 만료 잠금은 그대로입니다. 아래 GPS 주행 수집·자체 안내는 휴대폰 검토판 기능이며, Pleos 주행 사용 승인을 의미하지 않습니다.

## 실제 보행 경로로 계획하기

지도에서 실제 장소의 **보행 경로 확인하고 계획**을 누르면 OSM/FOSSGIS의 보행 전용 라우팅 서버에 출발점→장소→출발점 경로를 요청합니다. 자동차 경로나 직선거리를 보행 경로로 표시하지 않습니다. 가는 길과 돌아오는 길의 시간을 별도로 확보하고, 복귀 알림에는 실제 돌아오는 시간을 사용합니다. 보행 속도 상한 1.1m/s로 보수적으로 계산하고 분 단위로 올림합니다.

조회 전 장소 목록의 시간은 후보 비교용 추정입니다. 실제 장소는 왕복 경로 확인에 성공해야 출발 계획에 반영합니다. 원점이 10m 이상 달라지거나 확인 후 15분이 지나면 다시 확인합니다. 실제 경로가 없거나 응답·접근점이 불확실하면 계획을 확정하지 않습니다. 데모 예시 장소는 데모임을 유지하며 오프라인 선택이 가능합니다.

사용자가 요청할 때만 좌표를 전송하며 연속 요청 간격은 1.2초 이상입니다. [제공자 사용 정책·개인정보 안내](https://routing.openstreetmap.de/about.html), [OSM 지도 오류 제보](https://www.openstreetmap.org/fixthemap). 공용 서버는 서비스 보장을 제공하지 않습니다. 대규모 배포에는 자체 라우팅 서버 또는 계약된 제공자가 필요합니다. 계단·공사·출입시간·장애인 접근성의 실시간 정확성을 보장하지 않습니다.

공개 좌표 실조회: 판교·서울·도쿄·뉴욕 및 파리 거리 경로는 HTTP 200, 왕복 두 구간을 반환했습니다. 파리 에펠탑 부근의 처음 선택한 좌표는 HTTP 400 `NoRoute`였으며, 이를 성공으로 처리하지 않았습니다. 이 확인은 해당 좌표의 서버 응답 확인이며 실보행 검증이나 전세계 정확도 보장이 아닙니다. `WalkingServiceTest`의 판교 fixture는 실제 공개 응답이고, 나머지 단위 테스트의 좌표·급감속 입력은 합성 테스트 자료입니다.

## EchoRoad 연결·동작

[서버 실행 안내](../server/ECHOROAD.md). 내비 화면의 EchoRoad 설정에서 HTTPS 서버 주소와 기기별 접근 토큰을 넣습니다. 설정은 메모리에만 보관하며 앱 재시작 후 다시 연결합니다. 주변 정보 조회에는 현재 좌표가 전달됩니다. **급감속 후보 공유는 별도 동의해야 합니다.** 서버 미연결 시 제보가 다른 사용자에게 전송되거나 공개되지 않습니다.

정확도 10m 이내의 최신 실제 GPS, 속도 정확도 1.5m/s 이내에서 2회 연속 감속과 이동거리·방향 일관성을 확인합니다. 모의 GPS·단일 속도 튐·오래된 위치는 공유하지 않습니다. 30초 중복 제한을 적용합니다. GPS만으로 급감속 원인이나 사고를 확정할 수 없으며, 실차 센서와의 검증은 아직 필요합니다.

서버는 기기별 인증과 요청 제한을 적용합니다. 80m 이내·방향 차이 30도 이내의 **서로 다른 인증 기기 2개 이상**의 제보만 반복 급감속 후보로 제공합니다. 같은 기기의 반복 제보는 독립 확인으로 세지 않습니다. 저장 기간은 15분이며 전체 이동 궤적을 저장하지 않습니다. 앱은 최대 90초만 수신 결과를 유지하고, GPS 상실 시 즉시 지웁니다. 경로 앞쪽·진행 방향에 맞는 정보를 표시하며 음성 간격·중복 제한을 적용합니다. 데이터 없음은 안전하다는 뜻이 아닙니다.

## 공식 사고 다발 자료

현재 **발급된 API 키가 없어 공식 자료 미연결**입니다. [한국도로교통공단 공개 API 안내](https://opendata.koroad.or.kr/api/selectLgDataSet.do)의 실제 필드에 맞춘 가져오기 스크립트를 준비했습니다. 실제 인증 API 호출은 검증하지 못했습니다. 발급 후 서버 환경에 `KOROAD_API_KEY`를 설정하고 실행합니다. 키 값은 앱·저장소·채팅에 넣지 않습니다.

```bash
python3 scripts/fetch_accident_zones.py --year 2023 --sido 11 --sigungu 680 --output /secure/accident-zones.json
export CABIN_ACCIDENT_ZONES_JSON=/secure/accident-zones.json
```

행정코드·제공 연도를 공식 문서에서 확인하세요. 출력은 요청 지역에 한정됩니다. 과거 통계 연도를 명시하며 실시간 사고 발생 정보로 안내하지 않습니다. 서버의 유효기간 90일은 캐시 갱신 기한이고 통계 발생 시점을 바꾸지 않습니다. 실제 수입 자료를 검토한 뒤 서버를 재시작합니다. 실시간 사고 발생·도로 통제 피드는 별도 제공자 연결이 필요합니다.

## 검증과 남은 배포 조건

단위 테스트는 보행 비대칭 시간·만료·잘못된 응답, GPS 급변·감속·방향, 인증·중복 제보·반대 방향·TTL을 검사합니다. 로컬 HTTP 서버에서 두 인증 클라이언트의 전송→집계→조회 흐름을 실행합니다. 이는 실제 이용자 제보나 공공 사고 데이터로 수행한 실주행 검증이 아닙니다.

공개 서버는 아직 배포하지 않았습니다. 운영 HTTPS 도메인, 기기별 토큰 발급·폐기 체계, 인증 기기 남발 방지, 서버 부하·장애 감시, 개인정보 고지와 실제 도로 오탐 검증이 필요합니다. 이 조건이 갖춰지기 전에는 EchoRoad를 완성된 공공 안전 서비스로 홍보하지 않습니다. 기존 오프라인 카메라·방지턱 참고 자료와도 구분합니다.
