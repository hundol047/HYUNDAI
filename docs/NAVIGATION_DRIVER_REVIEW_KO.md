# 안내 화면 개선 및 남은 검증

휴대폰 검토본에서 안내 시작 시 확대 지도를 엽니다. 회전 방향과 회전까지 거리, 남은 거리, 신뢰 가능한 GPS 속도를 표시합니다. 사용자가 축소하면 현재 안내 중에는 축소 상태를 유지합니다. 확대 지도 이동·확대/축소·내 위치 추적 복귀는 기존 동작을 사용합니다.

확대 화면의 ‘다시 듣기’는 기존 음성 안내 서비스, ‘안내 종료’는 기존 위치·경로 종료 처리를 호출합니다. GPS 불확실 상태에서는 회전 안내와 속도 표시를 억제하고 상태·재탐색 오류를 표시합니다. 차량 안전 판정과 Pleos 차량의 정차 전용 정책은 바꾸지 않았습니다.

## 자동 검사

- `ExpandedNavigationMapTest.guidanceStartExpandsOnceAndManualCollapseSurvivesUpdates`: 안내 시작 자동 확대, 수동 축소 유지, 반복·종료 콜백.
- `ExpandedNavigationMapTest.activeLandscapeShowsTurnsAndControls`: 가로 화면의 거리·52dp 이상 주요 버튼 표시.
- 기존 휴대폰/가로 지도 확대 검사 및 `ApplicationTest.activeGuidanceKeepsRerouteConnectionFailureVisible`: 확대 화면에서도 오류 표시.

이 검사는 Robolectric UI 검사입니다. S20+ 실기기 주행, 지도 타일 서버 지연, 실제 음성 출력 또는 상용 내비와의 동등성을 검증한 것은 아닙니다.

## 카메라·과속방지턱

전국 방지턱 파일을 검증·변환한 참고 위치 및 조건부 음성 안내, 전국 고정식 단속시설의 참고 위치 및 거리 포함 참고 음성을 추가했습니다. 카메라 방향별 음성 경고는 미제공입니다. 범위·제외 기준은 [도로 안전시설 자료 검토](ROAD_SAFETY_DATA_KO.md)를 참조하세요. 교통 흐름 API의 응답으로 카메라나 방지턱 위치를 추정하지 않습니다. 출시 전 실제 데이터의 이용 허용 범위·갱신 시점·진행 방향·제한 속도·구간 단속 여부를 확인하고, 현재 경로에 있는 대상만 선별하는 처리와 실기기 경고 시점 검증이 필요합니다. 데이터가 없는 곳을 안전한 도로로 간주하거나 모든 도로의 경고를 보장하지 않습니다.

카카오맵·네이버맵·티맵의 비공개 소스 및 전체 앱 동작을 분석한 결과가 아닙니다. 실시간 교통 반영 경로, 차선 안내, 전체 도로 정체, 전국 카메라·방지턱 경고는 미완료입니다. 교통 연동의 현재 범위는 `server/TRAFFIC.md`를 참고하세요.
