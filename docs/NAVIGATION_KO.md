# EchoRoad 글로벌 자동차 내비게이션 (0.4.0)

Android APK와 브라우저에 실제 기기 위치·온라인 경로 서비스를 사용하는 내비게이션 기능을 구현했습니다. 검색에 한국 경계나 국가 필터를 두지 않습니다. 국가별 OSM 도로 데이터와 서비스 가용성이 달라 **전 세계 모든 도로에서의 작동을 보장하는 의미는 아닙니다**. 현재 클라우드에서 검색·경로 서버 연결이 차단되어 실서버·GPS 기기·실도로 검증은 아직 완료하지 못했습니다.

## 사용하기

1. 안전하게 주차한 상태에서 왼쪽 **내비**를 엽니다. 현 버전의 차량 기어·주차 상태는 데모이며 Pleos SDK 연결은 별도 미완료입니다. 기본 데모의 주차/충전 상태에서도 내비게이션은 실제 기기 GPS와 온라인 경로 서비스를 사용합니다.
2. **내 위치 사용**을 누르고 **정확한 위치**를 허용합니다. Android는 FINE 위치 권한, 브라우저는 HTTPS와 위치 권한이 필요합니다. API 29 이상 Android 기기에서 실행합니다. 위치 권한·GPS가 없으면 판교 예시 좌표 등으로 대체하지 않습니다.
3. `대한민국 서울역`, `Paris France`, `New York USA`, `東京駅` 등 국가·도시·주소를 입력하고 **검색**을 누릅니다. 또는 `48.8584,2.2945`처럼 **위도,경도**로 목적지를 정합니다. 입력 중 자동 검색은 하지 않습니다.
4. 검색 결과를 선택해 현재 위치에서 목적지까지 자동차 경로를 계산합니다. 지도에 표시하는 선은 OSRM이 반환한 도로 형상입니다. 서버가 경로를 찾지 못하면 오류를 표시하며 직선 경로를 만들지 않습니다. 차량 접근점이 위치/목적지에서 1km 이상 떨어지면 거부합니다.
5. 경로를 확인한 뒤 **안내 시작**을 누릅니다. 출발점 200m 이내, 10초 이내, 정확도 50m 이내 GPS가 필요합니다. 회전 방향·도로명·회전까지 거리, 남은 거리와 도착 예상 시간, 한국어 TTS를 안내합니다. 도로명은 원문 유니코드를 보존합니다.
6. 주행 중에는 목적지 입력·검색·지도 이동·확대 조작을 제한합니다. **안내 종료·경로 지우기**는 사용할 수 있습니다. 안내 중 정차 기능은 잠기며, 안내 종료 후에도 이동이 감지됐으면 즉시 잠금을 해제하지 않습니다. 속도 정보가 있는 정확한 GPS로 5초 이상 정지를 확인한 뒤에도 기존 차량 P 확인 절차를 다시 거칩니다. GPS는 실제 P 상태를 증명하지 않습니다.

## 안내와 재탐색

- Android와 브라우저는 같은 Kotlin `NavigationTracker`를 사용합니다. OSRM 회전 좌표는 색인으로 찾아 장거리 경로의 단계 매핑 비용을 줄입니다. 경로 선분에 위치를 투영해 진행 거리와 다음 회전을 계산하고, 날짜 변경선 경도 래핑과 교차점의 진행 연속성을 처리합니다. 이는 인증된 상용 map matching이 아닙니다.
- 경로에서 `max(45m, 정확도×2)` 이상 벗어나거나 이미 진행한 구간에서 60m 이상 역주행 방향으로 이동한 GPS가 3회 이상, 5초 이상 이어지면 자동 재탐색합니다. 재탐색은 최소 30초 간격, 연속 실패 3회 후에는 사용자 재시도를 기다립니다. 늦은 결과·화면 이탈·취소·오래된 위치로 경로를 시작하지 않습니다.
- GPS가 10초 이상 오래됐거나 부정확하면 회전 안내와 도착 예상 갱신을 멈추며 잠금을 유지합니다. 목적지 인근 30m·경로 잔여 50m 이내의 저속 위치가 연속 2회 확인돼야 도착으로 처리합니다.
- 음성은 한국어 TTS/브라우저 음성 서비스를 사용합니다. 기기에 한국어 음성팩이 없으면 화면 안내를 사용합니다. 안내 거리는 GPS 정확도·도로 데이터에 영향을 받습니다.
- 인터넷이 끊겨도 이미 받은 경로와 정확한 GPS의 안내는 유지합니다. 새 지도 타일, 목적지 검색, 경로 생성·재탐색은 인터넷이 필요합니다. 이 버전은 오프라인 지도를 내려받지 않습니다.
- 화면 밖에서는 GPS 요청과 안내를 중지하고 복귀 후 새 위치를 기다립니다. 백그라운드 내비게이션 서비스는 없습니다. 안내 중 화면은 켜 두도록 요청합니다.
- 실제 GPS 내비게이션이 활성화되면 예시 위험 이벤트를 실제 경로의 위험으로 표시하지 않습니다. 실시간 교통·차선·속도 제한·과속 단속·실제 위험 데이터·상용 도로 통행 규제 검증은 미제공입니다. 도착 예상은 서버의 비실시간 소요 시간에 진행 비율을 적용한 추정치입니다.

## 전 세계 데이터와 서비스 설정

| 기능 | 기본 서비스 | 요청 |
|---|---|---|
| 지도 | OpenStreetMap | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` |
| 목적지 검색 | Nominatim | `https://nominatim.openstreetmap.org/search?format=jsonv2&limit=6&q=...` |
| 자동차 경로 | OSRM | `https://router.project-osrm.org/route/v1/driving/{lon},{lat};{lon},{lat}?overview=full&geometries=geojson&steps=true` |

API 키 없이 기본 서비스로 요청하도록 구성했습니다. **공개 서버는 체험용이며 운영용 SLA가 없습니다.** 운영 시 `내비 → 서비스 설정`에서 Nominatim/OSRM 호환 자체·계약 HTTPS 서버로 바꾸세요. 주소는 세션 메모리에만 보관합니다. 기본 주소에는 계정/비밀번호·토큰 쿼리를 허용하지 않습니다. 브라우저용 자체 서버는 배포 페이지의 Origin에 대한 CORS 허용도 필요합니다. API 키가 필요한 비호환 상용 서비스는 별도 어댑터가 필요합니다.

검색은 버튼으로만 실행하고 1.5초 이상 간격, 결과 최대 6개·최근 30개 검색어 메모리 캐시를 사용합니다. 경로 요청도 1.5초 이상 간격을 둡니다. HTTP 연결/읽기·브라우저 전체 타임아웃, 응답 12MB, 경로 점 150,000개와 단계 10,000개 제한이 있습니다. Nominatim의 공개 서버 사용 정책상 대규모 배포 전 자체/계약 검색 서비스로 전환해야 합니다. 제공자에 현재 위치·목적지·검색어가 전송되므로 필요한 경우 자체 서버를 사용하세요. 위치 이력·목적지·검색어는 Room/파일/localStorage에 기록하지 않으며 개인 데이터 초기화 시 메모리 검색 캐시도 지웁니다. 지도 타일은 SDK 전용 캐시에 남을 수 있습니다.

OSM은 국가마다 주소·도로·접근 규제의 완전성이 다릅니다. 한국도 검색·경로 요청 대상에 포함되지만 모든 주소·도로가 연결된다는 보장은 없습니다. 섬/대륙/국경/차량 통행 불가 구간은 `NoRoute`가 정상 결과일 수 있습니다. 도로 형상이 없거나 지원하지 않는 지역에 가상의 길을 생성하지 않습니다. 웹 지도는 Web Mercator 표시 범위(약 ±85°)를 사용합니다. GPS와 경로 좌표 검증은 WGS84 ±90°/±180°입니다.

## 검증 범위와 남은 확인

한국·파리·뉴욕·도쿄·시드니·케이프타운 좌표의 공유 추적 계산, 날짜 변경선, 경로 오류·GPS 노후·정확도·중복·도착·재탐색·안전 잠금, Android JSON 파싱/실제 프레임워크 위치 콜백과 Compose 지도 생성, 실제 Chromium에서 검색·GPS 진행·재탐색·권한 거부·오프라인·모바일 UI를 검사합니다. 외부 서버와 위치 입력은 **명시적인 합성 테스트 응답/GPS**를 사용합니다. 합성 좌표의 성공을 해당 도시 실도로 성공으로 주장하지 않습니다.

2026-10-22 현재 클라우드 프록시가 Nominatim/OSRM 접속을 `Tunnel connection failed: 403 Forbidden`으로 차단합니다. 필요한 호스트를 설정 초안에 추가했으며 실제 적용·게시와 재검증은 남아 있습니다. 프록시를 우회하거나 다른 서버를 통해 차단된 자료를 가져오지 않았습니다. 실시간 타일·실제 검색 결과·실서버 자동차 경로와 물리 기기 GPS 주행, Pleos 기기 연동은 **미검증**입니다. [검증 보고서](VALIDATION.md)에 자동 검사와 이 제한을 분리해 기록합니다.
