# 부드러운 안내 말투와 목소리 선택

2026-10-27 (한국시간) · 퓨처랩스 CabinOS ONE

## 앱에 반영한 변경

- `잠시 후, 우회전입니다.` → `잠시 후, 우회전해 주세요.`
- `약 삼백 미터 앞에서, 우회전입니다. 한강대로 방면입니다.` → `약 삼백 미터 앞에서, 한강대로 방면으로 우회전해 주세요.`
- 합류·진출·갈림길도 `합류해 주세요`, `나가 주세요`, `진행해 주세요`처럼 짧은 요청형으로 통일했습니다. 가까운 회전에서는 긴 도로명을 생략합니다.
- 기본 말하기 속도를 0.94배로 설정했습니다. `차분한 말하기 속도`를 끄면 1.0배로 돌아갑니다. 엔진의 음높이는 변경하지 않습니다. 속도 지원과 실제 음색은 TTS 엔진에 따라 다릅니다.
- 설정의 `목소리 골라 듣기`에서 현재 내비 언어에 설치된 오프라인 목소리를 직접 들어보고 선택할 수 있습니다. 사용자가 선택한 목소리는 자동 품질 순위보다 우선합니다.
- 선택은 엔진·언어별로 저장하고 개인정보 삭제 시 초기화합니다. 저장한 목소리가 없어지면 설치된 적합한 음성으로 자동 선택합니다. 새 목소리 다운로드나 외부 음성 합성 API 연결을 추가한 것은 아닙니다.
- 목소리·속도 변경은 정차 상태에서 가능합니다. 기존 차량 잠금, 새로운 회전 안내의 우선 처리, 재생 실패 감지는 유지합니다.

## 음색과 비교 샘플

문장과 속도 조절만으로 모든 TTS 엔진이 사람처럼 들리지는 않습니다. 실제 목소리는 기기에 설치된 엔진·음성팩이 결정합니다. 품질 메타데이터만으로 '따뜻함'이나 성별을 판정하지 않고, 실제 안내를 들어보고 고를 수 있도록 했습니다.

비교 녹화에는 별도로 설치한 sherpa-onnx / Supertonic 3의 두 프리셋(0, 2)을 사용합니다. 프리셋은 엔진의 공개 설정 화면에서 선택하고 같은 APK의 같은 문장을 재생합니다. 이 엔진과 모델은 CabinOS APK에 포함되지 않습니다. 해당 엔진의 세부 화자 선택은 엔진 앱 설정에서 제공되며, CabinOS의 목소리 목록은 Android TTS가 공개한 목소리만 표시합니다.

[엔진 출처·라이선스·설정](NATURAL_VOICE_KO.md). 자연스러움과 편안함은 자동 전사나 음량 검사만으로 보증하지 않습니다.
