# 사고 다발구역 연결과 검증

2026-10-26 · 퓨처랩스

공개 서버: https://hyundai-production-1222.up.railway.app . 사용자가 전달한 공식 다운로드 CSV를 가공해 Railway 컨테이너에 기본 포함했습니다. API 키나 별도 Railway 변수 추가가 필요하지 않습니다. 공유 제보 조회·전송의 기존 기기별 인증은 그대로 유지합니다.

## 자료 선택

공식 한국도로교통공단 코드표로 모든 원본 데이터셋 ID 37개의 실제 통계 기간을 확인했습니다. ID의 앞 네 자리를 연도로 간주하지 않습니다.

| 유형 | 통계 기간 | 현재 안내 구역 |
|---|---|---:|
| 지자체별 | 2025년 | 683 |
| 보행자 | 2023~2025년 | 418 |
| 보행어린이 | 2025년 | 88 |
| 결빙 | 2021~2025년 | 82 |

총 1,271개 구역입니다. 이전 기간 9,093행은 최신 자료와 중복 안내하지 않도록 제외했습니다. 같은 장소의 유형별 영역은 별도 의미로 유지하며 사고 건수를 합산하지 않습니다. 최신 기간 안에서 동일 FID 중복은 0건입니다. 보행어린이 자료를 어린이보호구역 전용으로 표시하지 않습니다. 좌표 없는 지역별 통계 파일은 지도에 임의 배치하지 않습니다.

원본 출처·해시·변환 명령·연도 대응표: [데이터 설명](../server/data/README.md), [가공 감사 기록](../server/data/accident-zones-audit.json).

## 앱에서 확인

새 휴대폰 검토본에서 안전하게 정차한 상태로 **내비 → EchoRoad 연결 → 연결 확인**을 누릅니다. 서버 주소는 기본 입력됩니다. 인증 성공 후 ‘사고 다발 자료 연결’이 표시됩니다. 정확한 GPS 위치를 받아야 현재 위치 주변 자료를 조회합니다. 정차 상태에서도 위치가 확인되면 지도에 표시할 수 있습니다.

황색 경계와 표시점은 과거 통계 구역입니다. 확대 지도에서도 표시합니다. 안내 중에는 앞으로 700m 이내 예정 경로와 실제 구역 경계가 만나는 위치를 찾아 거리를 안내합니다. 이미 구역 안에 있으면 ‘현재 경로 주변’으로 표시합니다. 구역 중심점이 도로에서 멀다는 이유만으로 경로와 겹치는 구역을 누락시키지 않습니다. Polygon·MultiPolygon 및 내부 구멍을 처리합니다.

음성 예: ‘약 …미터 앞 경로 주변은 2021년부터 2025년 결빙 사고 이력 구역입니다. 현장 상황을 확인하세요.’ 이는 **현재 결빙·현재 사고 발생** 안내가 아닙니다. 정확한 GPS·경로 추적·기기 TTS가 필요하며 회전 안내 우선, 음성 중복·간격 제한을 유지합니다. 위험을 확인하려고 급제동하거나 주행 중 설정을 조작할 필요가 없습니다.

GPS 만료·경로 이탈·방향 불확실 시 위험 음성을 억제합니다. 조회 반경은 위치 중심 2km, 최대 50개 가까운 구역이며 응답 크기도 제한합니다. 초과하면 앱에 ‘가까운 일부 구역만 표시’를 알립니다. 제공되지 않는 사고 지역, 고가/지하도로 높이 차이, 출입·방향별 세부 조건까지 보장하지 않습니다. **모든 위험 구역 또는 상용 내비 수준의 정확도를 검증한 것은 아닙니다.**

검토 유효기한은 2026-12-28 00:00 UTC입니다. 이후에는 새 자료를 검토·갱신해야 하며 만료된 구역은 조회·음성에서 제외됩니다. 서버는 만료 이후에도 공유 제보 기능을 계속 실행합니다.

## 실제 서버 검증

[실제 HTTP 검사 기록](ACCIDENT_LIVE_VERIFICATION.json): 공개 서버의 1,271행 수와 데이터 SHA-256을 대조했습니다. 서울·강원·부산·제주 및 네 유형별 총 8건의 위치 조회에서 HTTP 200, 원본과 동일한 경계·기간을 확인했습니다. 미인증 공유 제보 조회는 HTTP 401로 계속 차단됩니다. 공공 통계 조회에서 개인 제보나 인증 정보를 반환하지 않습니다.

- `/v1/dataset`: 공개 자료 수·기간·해시. 개인 정보 없음.
- `/v1/accident-zones?lat=...&lon=...`: 공개 **과거 공공 통계** 조회. 공유 제보 포함 안 됨.
- `/v1/risks`: 기기 인증이 필요한 공공 통계 + 독립 기기 제보 조회. 앱이 사용하는 경로.

구역 교차·구역 내부·지나친 영역·옆 도로·MultiPolygon·구멍·오래된 GPS를 단위 테스트로 검사합니다. 검사 좌표의 HTTP 응답과 합성 경로 테스트는 실제 운전 검증과 다릅니다. 실제 사용자 접근키로 수행한 앱 수신, 삼성 S20+의 표시·TTS 출력, 도로 위 정확도는 이 환경에서 확인하지 않았습니다. Pleos 정차 전용 정책과 안전 잠금은 완화하지 않았습니다.
