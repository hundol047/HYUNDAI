# 실행 영상 검토 후 수정

초안 촬영 → 실제 녹화 파일의 프레임 확인 → 오류 수정 → 기능 검사 → 재촬영 순서로 진행했습니다.

## 초안에서 확인하고 고친 부분

| 발견 | 수정 | 확인 방법 |
|---|---|---|
| 할 일의 ＋ 버튼을 눌러도 목록이 추가되지 않아 촬영이 중단됨 | 전역 클릭 핸들러가 폼을 먼저 재생성하던 문제 수정. 할 일·어시스턴트·설정 모두 submit 이벤트를 유지 | 클릭과 Enter, 명령 실행, 설정 저장을 실제 Chromium에서 확인 |
| 주행/신호 대기 화면에도 안전한 주차 확인 문구가 표시됨 | 주차가 확인된 경우에만 표시 | 영상의 주행 구간 및 UI 검사 |
| 위험 안내 버튼이 모달을 먼저 열어 추가 조작을 요구 | 한 번 누르면 공유 엔진의 위험 답변을 읽고 화면에 표시. 한국어 음성이 없으면 텍스트 대체 | 모달이 열리지 않는지 자동 검사 |
| 연결 미확인 상태에 예시 지도·0 속도가 남아 실제 정보로 오해 가능 | 웹·Android 모두 UNKNOWN에서 경로·속도 대신 연결 상태 화면 표시 | 브라우저 실차 미지원 검사 및 Android Compose 검사 |
| 타이머 갱신으로 입력 중 문구가 지워질 가능성 | 입력값을 별도 보관, 설정 화면의 불필요한 분 단위 재생성 제거 | 폼 입력·제출 검사 |
| 작은 버튼과 일시정지 중 오디오 조작 | 체험 화면 버튼 최소 높이 48px, 정차 세션 실행 중에만 오디오 활성 | 데스크톱·모바일 렌더링 및 안전 상태 검사 |

Android에서도 앱 이탈 시 세션·오디오·음성 인식을 중지하고 차량 상태를 다시 확인하도록 보완했습니다. 실제 위치가 오래되거나 없을 때 지도 실행을 막고, 주행 중 새 마이크 권한 창을 열지 않습니다. 출발 계획을 앞당겼을 때 예전 알림이 남지 않도록 취소 처리도 보완했습니다. 출발 준비 시스템 알림, 선택 소스 복원, 정차 중 개인 데이터 삭제와 이력 보관을 추가했습니다.

## 최종 영상

[CabinOS_ONE_demo.mp4](video/CabinOS_ONE_demo.mp4)는 실제 Chromium 조작을 CDP로 캡처한 H.264 MP4입니다. 주행 → 신호 대기 → 주차 확인 → 충전 → 집중·할 일 → 충전 시간 단축 → 일시정지 → 휴식 → 출발 준비 → 재출발 → 연결 손실 → Android UI 갤러리를 보여줍니다. 한국어 설명 자막이 포함되며 별도 음성 내레이션은 없습니다.

영상의 할 일 완료와 타이머 단축, 재출발 안전 제한, 연결 손실 화면, Android 갤러리 구간을 다시 추출해 확인했습니다. 원본 초안과 중간 캡처는 생성물 `artifacts/video-review/`에 보관하고, 최종 MP4와 검증 메타데이터를 저장소에 포함합니다.

영상은 **브라우저 시뮬레이션의 실행 녹화**입니다. Android 갤러리는 실제 Compose UI를 Robolectric에서 렌더링한 이미지이며, 실제 차량 또는 APK의 기기 실행을 녹화했다고 주장하지 않습니다. 실제 기기 실행 검증의 한계는 [VALIDATION.md](VALIDATION.md)를 확인하세요.
