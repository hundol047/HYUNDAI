# 내비 음성의 끊김·문장·엔진 품질 개선

최신 변경: [말투·합류·출구 표현과 실제 재생 오류 처리](VOICE_GUIDANCE_REVIEW_KO.md). 아래는 엔진 설정과 이전 개선의 배경입니다.

기존 공개 영상은 eSpeak NG의 합성음을 녹음했습니다. 오디오가 있다는 확인만으로 자연스러운 발음을 검증했다고 볼 수 없어, 새 녹화에는 오프라인 신경망 TTS를 사용합니다.

## 앱에서 바뀐 부분

- 한국어는 화면의 ‘유턴 · 한강대로’ 대신 ‘약 천백 미터 앞에서 유턴하세요. 한강대로 방면입니다.’처럼 완성된 문장을 읽습니다. 다른 내장 언어에서도 화면 구분 기호를 말하기 문장에 그대로 넣지 않습니다.
- 음성 거리만 100m 이상에서 10m, 1km 이상에서 100m 단위로 반올림합니다. 경로 진행도·도착·회전 판단·화면의 원본 거리는 바꾸지 않습니다.
- 자동 안내에서 목적지 이름을 발화하자마자 첫 회전 안내로 취소하던 중복 요청을 제거합니다. 수동 경로 미리보기의 목적지 읽기는 유지합니다.
- 같은 언어를 발화할 때마다 다시 설정하지 않습니다. 재생 중인 동일 문장을 반복 요청해도 처음부터 다시 시작하지 않습니다. 일반 정차 상태 메시지가 재생 중인 내비 안내를 끊지 않습니다. 새로운 회전 안내·신호 상실·안전 잠금에 의한 중지는 유지합니다.
- 현재 기본 엔진이 보고하는 음성 중, 요청 언어·지역에 맞는 설치된 오프라인 음성을 우선하고 그 안에서 품질·지연 정보를 비교합니다. 온라인 음성을 자동 선택하지 않습니다. 기기 설정에서 엔진을 바꾸고 복귀하면 새 엔진으로 연결합니다.
- 앱 설정에 ‘안내 음성 들어보기’와 ‘기기 음성 설정’을 추가합니다. 실제 목소리는 기기의 기본 TTS 엔진과 설치된 음성팩에 따릅니다.

## 녹화용 신경망 엔진

녹화용 Android 에뮬레이터에는 **sherpa-onnx TTS Engine 1.13.8 / Supertonic 3 int8**을 별도로 설치합니다. 앱이 Android TextToSpeech API로 요청한 문장을 이 엔진이 기기 안에서 합성합니다. 특정 사람의 목소리를 복제하거나 외부 내레이션을 영상에 덧붙이지 않습니다.

- 엔진 코드: [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), Apache-2.0.
- 모델: [Supertone Supertonic 3](https://huggingface.co/Supertone/supertonic-3), [BigScience Open RAIL-M](https://huggingface.co/Supertone/supertonic-3/blob/3cadd1ee6394adea1bd021217a0e650ede09a323/LICENSE).
- 엔진 APK 출처: [프로젝트 공식 빌드 배포](https://huggingface.co/csukuangfj2/sherpa-onnx-apk/tree/7655c70a179a5a574f62f1723a13db1c60a83f2f/tts-engine-new/1.13.8). 버전·모델·언어·SHA-256을 녹화 워크플로에 고정했습니다.
- 네트워크 음성 합성 API·키를 사용하지 않습니다. 모델과 엔진 APK를 CabinOS 저장소나 앱에 재포장하지 않았습니다.

## 휴대폰에서 확인

1. CabinOS 설정 → **기기 음성 설정**에서 삼성 또는 Google 등 사용하는 엔진을 선택합니다.
2. 해당 엔진에서 한국어 등 필요한 고품질 오프라인 음성팩을 설치합니다. 같은 엔진에 음성팩만 새로 추가했다면 앱을 완전히 종료한 뒤 다시 실행해 확인하세요.
3. CabinOS 내비에서 언어를 선택하고 설정의 **안내 음성 들어보기**를 누릅니다.

영상과 같은 목소리가 필요하면 위 공식 배포의 해당 언어 Supertonic 3 엔진을 별도로 설치하고 기기 기본 엔진으로 선택해야 합니다. 별도 다운로드가 필요한 약 150MB의 엔진이며, 휴대폰·차량의 설치 정책과 지원 여부를 확인해야 합니다. CabinOS APK만 설치하면 영상과 같은 목소리가 자동으로 추가되는 것은 아닙니다.

## 검증 범위

31개 내장 번역의 말하기 문장 구성과 대표 언어의 오프라인 음성 선택을 테스트합니다. 한국어의 실제 경로 안내와 영어·일본어·프랑스어·독일어의 앱 미리듣기 녹음을 구분합니다. 자동 오디오·전사 검사는 실제 사람의 청취 평가나 모든 언어의 자연스러움을 보증하지 않습니다. 삼성 S20+ 및 Pleos 실기기의 스피커·엔진 성능 검증은 별도입니다.
