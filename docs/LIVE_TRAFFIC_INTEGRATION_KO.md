# 실시간 교통 연결에 필요한 사항

현재 OSM 래스터 지도와 OSRM 경로는 실시간 교통을 제공하지 않습니다. 경로 색상은 교통 상태가 아닙니다. 교통 데이터 없는 도로를 녹색으로 표시하지 않습니다.

## 데이터 연결

- 한국: 국가교통정보센터 Open API 신청 및 이용 범위 확인: https://www.its.go.kr/opendata/
- 다국가: TomTom Traffic API 등 계약 데이터의 국가별 커버리지와 지도 중첩 표시 권한 확인: https://developer.tomtom.com/traffic-api/documentation/traffic-flow/flow-segment-data
- 키를 채팅·APK·저장소에 넣지 않습니다. 인증된 서버에서 보관하고 앱에는 필요한 교통 데이터만 제공합니다. 현재 이 서버와 데이터 이용 권한은 구성되지 않았습니다.

## 표시 및 안내 기준

- 제공자의 정체 등급을 우선 사용하여 정체=빨강, 서행=노랑, 원활=초록으로 표시합니다. 속도 비율을 사용할 경우 도로 종류별 기준과 공급자 권장 기준을 검증해야 합니다.
- 도로 구간 형상·진행 방향·현재 속도·평상시 속도·수집 시각·폐쇄 여부를 함께 처리합니다. 반대편 도로의 교통을 현재 경로에 붙이지 않습니다.
- 데이터 없음·만료는 회색 ‘교통 정보 없음’으로 표시합니다. 공급자 갱신 주기를 지키고 오프라인에서는 최신인 것처럼 표시하지 않습니다.
- 단순 교통 색상 중첩만으로 OSRM의 도착 시간·우회 경로가 교통을 반영하지는 않습니다. 교통 반영 경로 API와 별도 연결해야 합니다.
- 지연 안내 음성은 같은 구간·사건을 반복하지 않고, 실제 경로의 앞쪽 구간에 해당하는 경우에만 말합니다.

이번 변경은 검색/내 위치 버튼과 안내 반복/종료 조작의 접근성을 개선한 것입니다. 실시간 교통 수신이나 교통 반영 길 안내 구현 완료를 의미하지 않습니다.
