# 안내 말투와 재생 상태 점검

## 비교 근거와 적용 범위

2026-10-26에 다음 공식 공개 문서를 확인했습니다.

- [카카오모빌리티 길찾기 응답](https://developers.kakaomobility.com/guide/navi-api/directions.html): 거리·안내 타입·도로 인덱스·guidance 문자열을 구분합니다. 예시의 `우회전`은 경로 안내 데이터이며 실제 음성 녹음이 아닙니다.
- [카카오 내비 UI SDK 주행 안내](https://developers.kakaomobility.com/guide/android-ui/driving.html): 음성 재생 여부·시작·완료 콜백을 구분합니다. CabinOS는 이 SDK를 도입한 것이 아니라 Android TTS의 재생 콜백을 사용합니다.
- [티맵 자동차 경로안내](https://tmapapi.tmapmobility.com/webservice/docs/tmapRouteDoc.html): `description`, `nextRoadName`, `turnType`과 좌·우회전, 갈림길, 고속도로 진입·진출, 회전교차로 출구를 구분합니다.

카카오맵·티맵 앱을 직접 주행시켜 음원을 청취하거나 음색·억양을 계측한 비교는 아닙니다. 공개 안내 데이터와 재생 생명주기를 검토했습니다. 두 회사 음성·성우를 복제하거나 음원을 가져오지 않았습니다. 동일 수준의 지도·교통·차선·안내 정확도를 주장하지 않습니다.

## 변경

- 화면 문구를 그대로 읽는 대신 실제 회전 데이터에서 음성 문장을 구성합니다. 한국어는 `약 삼백 미터 앞에서, 우회전입니다.`처럼 거리와 동작을 짧게 구분합니다.
- 회전까지 20m 이하에서는 `잠시 후, 우회전입니다.`처럼 긴 도로명을 생략합니다. 이 조건은 음성 표현에만 적용하며 회전 판정·GPS 신뢰도·주행 안전 잠금은 바꾸지 않습니다.
- 합류는 `왼쪽 도로로 합류하세요`, 진출은 `오른쪽 출구로 나가세요`, 회전교차로는 `세 번째 출구로 나가세요`처럼 구성합니다. 데이터에 없는 차선이나 교차로 이름은 생성하지 않습니다.
- 음성 거리는 1km 이상이면 언어·지역에 맞는 킬로미터 단위로 읽습니다. 화면과 경로 계산의 원본 거리는 유지합니다.
- 프랑스어 화면용 부정사를 안내용 명령형으로 변환합니다. 모든 내장 언어에서 시각적 구분 기호·줄바꿈을 정리하고 문장 끝을 구분합니다. 대표 언어의 도착 전 안내는 완료된 도착으로 읽지 않습니다.
- 비슷한 품질의 오프라인 음성이 여러 개면 엔진이 선택한 기본 음성을 유지합니다. 음성 선택 API 실패를 성공으로 표시하지 않습니다.
- 합성 대기부터 발화 종료까지 같은 요청의 재시작과 일반 알림의 끼어들기를 막습니다. 새 회전 안내와 안전 중지는 계속 우선합니다.
- 같은 문구라도 다음 교차로의 안내라면 생략하지 않도록 교차로 식별값을 함께 비교합니다.
- 실제 TTS 재생 오류를 감지하고, 이전 발화의 늦은 오류가 현재 안내 상태를 덮어쓰지 않게 합니다. 재생 시작 콜백 없이 8초가 지난 요청은 취소하고 화면에 지연을 알립니다. 지연 시간을 개선했다고 주장하는 기능이 아니라 오래된 안내가 뒤늦게 나오는 것을 제한하는 기능입니다.

## 목소리 자체의 한계

문장과 재생 코드를 바꿔도 기본 TTS 엔진의 음색·억양 모델이 바뀌지는 않습니다. `설정 → 기기 음성 설정`에서 원하는 엔진·설치된 고품질 음성팩을 선택한 뒤 `안내 음성 들어보기`로 확인할 수 있습니다. [엔진과 별도 신경망 모델 안내](NATURAL_VOICE_KO.md).

31개 언어의 문장 구조 테스트는 원어민 청취 평가가 아닙니다. 대표 언어 녹화도 실제 차량·스마트폰 스피커에서의 지연·자연스러움을 보증하지 않습니다. 사용자 발화나 도로명을 새 외부 음성 서비스에 전송하지 않습니다.
