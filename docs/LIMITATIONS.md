# 알려진 제한과 남은 작업

1. **Pleos SDK/실차 미연동:** 공식 문서 및 SDK 접근이 선행되어야 합니다. 현재 Vehicle/Charging은 데모이며 실제 신호를 읽는 구현이 없습니다. `실차 연결`은 UNKNOWN으로 기능을 제한하는 실패 경로입니다. 차량 하드웨어·특권 권한·공조/조명·OEM distraction 정책은 검증되지 않았습니다.
2. **데모 지도와 위험 정보:** 지도는 자체 Canvas로 그린 개념 경로이며 실제 지도 타일/턴바이턴 내비게이션이 아닙니다. 위험 이벤트는 테스트용 로컬 데이터입니다. 실제 급감속 검출·크라우드 소싱·위험 업로드는 없습니다. 점수·필터·알림 로직은 구현되어 있습니다.
3. **주변 장소:** 모두 예시 장소입니다. 실제 영업시간·거리·혼잡도·예약 가능 여부를 제공하지 않습니다. 이동 시간은 예시 데이터이며 왕복/복귀 가능성 계산에 사용합니다. 실제 POI API 계약과 네트워크 어댑터가 필요합니다.
4. **어시스턴트:** 제한된 한국어 명령을 규칙으로 처리합니다. 범용 생성형 AI나 임의 대화가 아닙니다. 안전 상태와 명령 실행은 중앙 엔진이 결정합니다. TTS/STT는 플랫폼 어댑터를 연결했지만 언어팩/인식 서비스에 의존합니다. 오프라인 STT는 요청할 뿐 서비스 제공을 보장하지 않습니다.
5. **오디오:** 저음량 배경 소리를 로컬 생성합니다. 음악 스트리밍·저작권 콘텐츠·차량 오디오 제어는 아닙니다. 실제 음량·오디오 포커스·차량 오디오 존 검증은 필요합니다.
6. **실행 수명:** 화면 내 타이머와 이벤트 안내를 제공합니다. 백그라운드 Foreground Service, 정확한 알람, 부팅 후 자동 실행, 알림 채널/시스템 알림은 미구현입니다. 앱이 죽거나 백그라운드 제한을 받으면 출발 알림을 보장하지 않습니다. 재실행 시 저장된 일정과 일시정지 세션을 복원합니다.
7. **개인정보/저장:** 외부 전송과 Android 자동 백업은 비활성입니다. 동의 토글은 로컬에만 저장합니다. 설정 초기화·전체 데이터 삭제 UI, 데이터베이스 암호화, 서버 보관 정책은 추가 구현 대상입니다. 앱 데이터 삭제/제거로 로컬 데이터를 삭제할 수 있습니다.
8. **모드/기기 복원:** 도메인은 UNKNOWN에서 시작합니다. 이 데모는 재실행 시 충전 시뮬레이터로 시작하며 실제 차량 모드 선택을 영구 유지하지 않습니다. 활성 세션은 일시정지로 복원됩니다.
9. **서명/제출:** 제출용 release APK는 전용 팀 인증서로 서명하며, 키와 비밀번호는 저장소 밖에 보관합니다. 별도 개발 인증서로 서명한 데모 APK와 구분합니다. 후속 업데이트를 위해 서명키를 안전하게 백업해야 합니다. 공모전의 실제 제출 APK 버전/서명/형식 요구는 공식 안내 접근 후 확인해야 합니다.
10. **실제 검증 범위:** 도메인 테스트·Android 빌드·Lint와 실행한 장치 검사만 검증 보고서에 기록합니다. 일반 Android 에뮬레이터 검증은 AAOS 실차·Pleos 환경 검증을 대체하지 않습니다. 시연 영상과 사업계획서 제출본은 별도 준비가 필요합니다.

현재 구현을 차량 안전 기능으로 의존해서는 안 됩니다. 공개 위험·지도·충전 정보를 검증된 경로로 통합하고 실제 차량에서 테스트한 후 서비스 범위를 확장해야 합니다.
