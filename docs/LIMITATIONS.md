# 알려진 제한과 남은 작업

1. **Pleos 대상 장치 미검증:** AAOS `CarPropertyManager` 속도·기어 읽기 어댑터는 구현·기본 빌드·합성 입력/UI 테스트를 완료했습니다. 공식 Vehicle 2.3.2 브레이크 조회는 선택 프로필에 구현했으나 AAR/에뮬레이터 다운로드 호스트가 프록시 403으로 차단되어 SDK 포함 빌드·Pleos 실행 영상은 남아 있습니다. 기존 배포 APK는 0.10.5이며 이번 코드를 포함하지 않습니다. 충전·배터리 실차 신호, OEM distraction 정책과 차량별 권한은 미검증입니다. [정확한 범위와 재개 절차](PLEOS_VEHICLE_STATE_KO.md).
2. **내비게이션과 위험 정보:** 기존 홈의 주행 경로는 Canvas 데모입니다. 별도 `내비` 화면에 실제 GPS·Nominatim 목적지 검색·OSRM 자동차 경로·회전 안내·재탐색을 구현했습니다. 한국 등 국가 제한은 없지만 OSM 도로/주소 완전성·전 세계 모든 도로의 호환성은 보장하지 않습니다. 기본 공개 서버는 체험용이며 자체/계약 서비스로 바꿀 수 있습니다. OSM/Nominatim/OSRM 실제 연결과 브라우저 서울 경로를 확인했습니다. GPS 실도로 실행과 상용 내비게이션 수준의 정확도는 미검증입니다. NAVIGATION_KO.md를 확인하세요. 정차용 지도는 같은 OSM 타일을 사용하며 0.10.5에서 실제 Overpass 주변 검색 3개 도시 응답을 확인했습니다. 공공 서버 지연과 데이터 누락은 남아 있습니다. 위험 이벤트는 테스트용 로컬 데이터입니다. 실제 급감속 검출·크라우드 소싱·위험 업로드는 없습니다. 점수·필터·알림 로직은 구현되어 있습니다.
3. **주변 장소:** 처음에는 예시 목록이며, 명시적 주변 검색으로 OSM 등록 장소를 요청하는 어댑터를 추가했습니다. 도보 시간은 직선거리 기반 추정이며 실제 보행 경로나 영업 여부를 검증하지 않습니다. 0.10.5 실서버 검사에서는 리스본·서울·웰링턴에서 각각 60개 장소를 받았습니다. 모든 장소·영업 상태의 완전성은 검증되지 않았습니다. 상세 범위는 MAPS_KO.md를 확인하세요.
4. **어시스턴트:** 제한된 한국어 명령을 규칙으로 처리합니다. 범용 생성형 AI나 임의 대화가 아닙니다. 안전 상태와 명령 실행은 중앙 엔진이 결정합니다. TTS/STT는 플랫폼 어댑터를 연결했지만 언어팩/인식 서비스에 의존합니다. 오프라인 STT는 요청할 뿐 서비스 제공을 보장하지 않습니다.
5. **오디오:** 저음량 배경 소리를 로컬 생성합니다. 음악 스트리밍·저작권 콘텐츠·차량 오디오 제어는 아닙니다. 실제 음량·오디오 포커스·차량 오디오 존 검증은 필요합니다.
6. **실행 수명:** 화면을 벗어나면 세션을 일시정지하고 차량 신뢰를 초기화합니다. 저장한 계획의 출발 준비 시각에 비정확 시스템 알림을 예약합니다. Android 13+ 알림 권한이 필요하며 절전 정책으로 지연될 수 있습니다. Foreground Service, 정확한 알람, 부팅 후 자동 복원은 없습니다. 강제 중지·재부팅 후에는 앱을 다시 열어야 하며 알림 시각을 보장하지 않습니다.
7. **개인정보/저장:** 자동 백업과 위험 업로드는 비활성입니다. 사용자가 지도·검색·길 안내를 요청하면 타일 영역·검색어·경로 좌표를 선택한 OSM/Nominatim/OSRM/Overpass 서버에 전송합니다. 실제 좌표·목적지·검색어는 Room/파일에 기록하지 않습니다. 동의 토글은 로컬에만 저장합니다. 정차 중 설정에서 확인 후 개인 설정·할 일·세션·일정을 삭제할 수 있습니다. DB는 최근 이력 100개와 활성 세션을 보관합니다. 데이터베이스 암호화·서버 보관 정책은 미구현입니다.
8. **모드/기기 복원:** 도메인은 UNKNOWN에서 시작합니다. 첫 실행은 충전 시뮬레이션이며 이후 선택한 소스를 보관합니다. 실차 연결 선택 후 재실행해도 UNKNOWN을 유지하고 시뮬레이션 주차로 되돌리지 않습니다. 활성 세션은 일시정지로 복원됩니다.
9. **서명/제출:** 제출용 release APK는 전용 팀 인증서로 서명하며, 키와 비밀번호는 저장소 밖에 보관합니다. 별도 개발 인증서로 서명한 데모 APK와 구분합니다. 후속 업데이트를 위해 서명키를 안전하게 백업해야 합니다. 공식 저장소·파일명·README 요구는 확인했습니다. Pleos 환경의 실제 실행 호환성은 별도 검증이 필요합니다.
10. **실제 검증 범위:** 도메인 테스트·Android 빌드·Lint와 실행한 장치 검사만 검증 보고서에 기록합니다. 일반 Android 에뮬레이터 검증은 AAOS 실차·Pleos 환경 검증을 대체하지 않습니다. 브라우저 시연 영상은 공유 Kotlin 엔진을 실행한 녹화이며 Android APK의 실제 기기 실행 영상이나 실차 검증 영상이 아닙니다. 사업계획서 제출본은 별도 확인이 필요합니다.

현재 구현을 차량 안전 기능으로 의존해서는 안 됩니다. 공개 위험·지도·충전 정보를 검증된 경로로 통합하고 실제 차량에서 테스트한 후 서비스 범위를 확장해야 합니다.

11. **브라우저 체험:** 동일한 Kotlin 엔진을 사용하지만 할 일·체험 기록은 탭 메모리에만 보관하며 새로고침하면 초기화됩니다. Android 앱은 Room에 저장합니다. 웹 음성은 브라우저의 한국어 음성 지원에 의존하고 없으면 화면으로 안내합니다. [공개 체험 페이지](https://hundol047.github.io/HYUNDAI/)는 배포됐으며 데모·Android 갤러리·APK 다운로드를 제공합니다.


0.7.0의 가게명·지점·주소 검색, 제공되는 전화/등록 영업시간, 20km·더 보기·지도 핀, 실제 표본/오류와 선택적 카카오 서버 범위는 [가게 검색 안내](PLACE_SEARCH_KO.md)에 있습니다. 모든 도로/가게를 보장하지 않으며 카카오 실서버는 키 미등록으로 미검증입니다. Google Maps는 외부 검색 링크이며 Google Places API 연동은 아닙니다.


0.9.0의 GPS 연결/정차 갱신/복구/권한 안내와 현재 기능 판정·실기기 한계는 [GPS 재점검](GPS_REVIEW_KO.md)을 기준으로 확인하세요.
