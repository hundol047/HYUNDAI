# 공모전 시연 시나리오

모든 시연 화면에 **데모 모드 — 시뮬레이션 데이터**가 표시됩니다. 실제 주행 데이터를 수집·검출했다고 설명하지 않습니다.

1. 앱 실행: 약 2초 후 P 상태가 확인되면 정차 대시보드 표시. 상단 StopSense와 하단 CabinOS가 함께 활성화되는 점을 설명합니다.
2. 왼쪽 `데모` → `주행` → 대시보드 복귀. EchoRoad와 경로 위험 정보가 자동 표시됩니다. 한국어 음성팩이 설치된 기기라면 위험 안내가 재생됩니다.
3. `신호 대기`: 속도 0이어도 D 기어이므로 EchoRoad를 유지합니다. 집중·휴식·주변 활동 및 설정 진입을 차단합니다. 음성 어시스턴트로 집중을 요청해도 안전 규칙이 우선합니다.
4. `주차`, 이어서 `충전`: P가 1.5초 이상 유지되면 자동 전환. StopSense 충전 예상 40분, 출발 준비 5분, 활동 가능 약 35분. 주변 장소는 예시이며 왕복 시간을 반영합니다.
5. `집중 모드` 시작: 25분 세션과 할 일 목록. 할 일을 추가하고 완료 표시합니다. 오디오 프리셋을 눌러 로컬 배경 소리를 재생할 수 있습니다.
6. `충전 15분`: 동일 세션의 남은 시간이 약 10분으로 줄어듭니다. 독립된 두 타이머가 아니라 공유 출발 계획에 반응하는 모습을 보여줍니다.
7. 세션 종료 후 휴식 시작: 산·숲 배경, 호흡 안내, 출발 시간 동기화. 휴식 중에도 StopSense가 함께 보입니다.
8. `출발 준비`: 남은 충전 5분, 준비 여유 5분이므로 활동 세션을 종료하고 출발 알림을 표시합니다.
9. `주행`: 자동 EchoRoad 복귀. 진행 중인 정차 세션은 안전하게 일시정지되고 생산성 화면은 사라집니다.
10. 정차 복귀 후 `기록`과 `설정`에서 세션 이력·프리셋 저장을 확인합니다.

`전체 시나리오 실행`은 위 상태 전환을 약 30초에 걸쳐 실행합니다. 시뮬레이터 창을 닫으면 대시보드가 자동 전환되는 모습을 관찰할 수 있습니다.

예외 시연: `SDK 끊김` → UNKNOWN/제한, `위치 거부` → 경로 위험 제거, `네트워크 끊기` → 로컬 타이머·세션 유지, `실차 연결` → 미지원 상태를 명확히 표시. 앱 강제 종료 후 다시 열면 설정과 세션 진행은 저장되지만 세션은 자동 재개하지 않습니다.

제출 영상에는 실제 동작 범위와 미연동 SDK 항목을 함께 설명하고, 최종 제출 형식·실제 APK 요구 버전은 공식 공모전 안내에서 별도로 확인해야 합니다.

## 녹화본과 웹 체험

[최종 실행 영상](video/CabinOS_ONE_demo.mp4)은 한국어 자막이 있는 실제 브라우저 조작 녹화입니다. Android 앱과 동일한 Kotlin 엔진을 실행하며, 마지막에는 실제 Compose UI 갤러리와 APK 다운로드를 보여줍니다. APK 실기기·실차 실행 영상은 아닙니다.

[영상 확인 후 수정 내역](VIDEO_REVIEW.md)과 [웹 배포 상태](WEB_DEMO.md)를 함께 확인하세요. 영상 파일은 GitHub 저장소에 포함되므로 작업 환경이 종료되어도 저장소 링크로 내려받을 수 있습니다.
