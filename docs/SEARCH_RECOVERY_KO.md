# 0.10.5 검색 누락·주변 추천 후속 수정

팀 퓨처랩스 · 2026-10-24. 이전 5시간 검사에서 빈 결과였던 상호 9건과 주변 추천 서버 시간 초과를 재검사했습니다. 실제 제공자 응답을 사용했으며 GPS 입력은 공개 좌표를 이용한 합성 위치입니다. 모든 가게·지점의 등록 상태나 실제 영업을 확인한 결과는 아닙니다.

## 수정한 동작

- 빈 검색 뒤 **지역을 나눠 주변 후보 찾기**를 직접 누를 수 있습니다. 원래 검색어를 유지하며, 지역과 상호를 분리하고 실제 응답의 지역 별칭·업종·이름·좌표를 대조합니다. 자동으로 다른 지점을 선택하거나 길 안내를 시작하지 않습니다.
- 광화문·반월당역·두바이 몰 같은 기준점은 **1.2km**, 일반 도시·지역은 **20km**로 후보를 제한합니다. 화면에 실제 기준 지역과 반경을 표시합니다. 현지어와 등록된 영문 브랜드 별칭 결과를 합치고 해당 지역에 가까운 순서로 최대 6곳을 제시합니다.
- 같은 도시 이름의 역 때문에 지역을 잘못 고르거나, 두 단어 지역명을 더 짧게 잘라 다른 나라로 넘어가던 경로를 막았습니다. 동명 지역을 하나로 판별할 수 없으면 자세한 지역명을 요청합니다.
- `Padaria Bella Paulista`의 동명 신문 판매점, `Hotel Belvedere`의 교통 정류장, 이름 일부만 같은 다른 빵집을 제외합니다. 업종을 명시한 경우 해당 업종 검색도 사용합니다.
- 가게가 지도 데이터에 없으면 **지도 중심을 목적지로** 직접 지정할 수 있습니다. `직접 고른 지도 지점`, `상호·주소 미확인`으로 표시합니다. 차량 GPS를 바꾸거나 누락 가게를 찾았다고 간주하지 않습니다. 실제 자동차 경로 계산과 기존 GPS·접근 지점 확인 절차를 거칩니다.
- 검색 캐시는 60초 후 갱신할 수 있습니다. 지역 검색은 취소·화면 이탈·주행 전환 뒤 늦게 온 응답을 반영하지 않습니다. 음성 명령 `지역 나눠 찾기`도 정차 제한을 따릅니다.
- 주변 추천은 Overpass에서 작은 반경을 먼저 계산하는 쿼리와 POST 전송으로 바꿨습니다. 최대 대기는 35초이며 검색 취소가 가능합니다. 서버가 HTTP 200과 함께 불완전 결과를 알리는 `remark`를 보내면 빈 정상 결과로 처리하지 않고 기존 목록을 유지합니다.

## 실행·녹화·회귀 확인

브라우저 검사는 실제 Chromium의 조작·취소·주행 차단을 실행합니다. 자동 회귀 검사의 공급자 응답은 fixture이며 실서버 검사는 위 별도 기록을 기준으로 합니다. 최신 수치와 빌드 해시는 [검증 결과](VALIDATION.md)에 있습니다. 이전 [5시간 모의주행](WORLD_SOAK_KO.md)은 당시 기록으로 보존하며 이번 재검사 시간을 더하지 않았습니다.

[새 실행 영상](video/CabinOS_ONE_search_recovery_v0105.mp4)은 실제 브라우저의 검색·주변 추천·경로 계산을 연속 녹화한 것입니다. 사진 슬라이드가 아닙니다. 녹화 후 모바일 확인에서 지도 목적지 버튼이 공통 스타일 때문에 44px로 줄어든 점을 발견했고, 최종 배포에서는 48px로 고친 뒤 390px 화면에서 다시 확인했습니다. 영상은 이 4px 터치 영역 수정 직전 화면입니다. 영상은 **78.28초**이며 GPS는 합성 입력입니다. Android 실기기·실차 녹화가 아닙니다. [녹화 요청·장면 기록](../test-fixtures/validation/search-recovery-video-v0105/results.json)을 함께 보관합니다.

재현: `node scripts/web/verify-search-recovery-live.cjs`, `node scripts/web/verify-nearby-provider-live.cjs`, `node scripts/web/record-search-recovery.cjs`. 실제 외부 서비스를 쓰므로 CI에서 반복 실행하지 않습니다. 이 클라우드에서 녹화할 때는 `PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright`를 설정해 설치된 FFmpeg를 사용합니다. 내부 HTTPS 프록시·CA 신뢰를 유지하며 우회 경로나 TLS 검증 해제는 사용하지 않습니다.
