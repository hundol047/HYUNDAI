# 음성 길찾기·글로벌 안내 언어 · 0.10.0

Android 앱과 브라우저 데모 모두에서 목적지 음성 입력 → 결과 번호 선택 → 명시적 안내 시작을 구현했습니다. 음성 인식·TTS API를 실제로 연결했지만 **이 환경에서는 물리 마이크, 실제 인식 제공자의 음성 정확도, 기기 스피커/언어팩을 검증하지 못했습니다.** 자동 검사의 음성 결과와 GPS는 명시적 시험 입력입니다.

## 사용법

1. 안전하게 주차한 상태에서 내비 화면의 **음성 길찾기**를 누르고 마이크 권한을 허용합니다. 현재 위치 권한과 GPS도 필요합니다.
2. `서울역`, `Café Paris`, `Navigate to Starbucks Paris`처럼 가게·지점·도시·주소를 말합니다. 검색 결과에 번호를 표시하고 음성팩이 있으면 결과 이름도 읽습니다.
3. 다시 음성 버튼을 누르고 `1번`, `2번`, `one`, `two`, `1`, `2`처럼 결과 번호를 말합니다. 선택한 가게의 자동차 경로를 계산합니다.
4. 경로 확인 후 `안내 시작` 또는 `start navigation`을 말합니다. 목적지와 차량 접근 지점의 차이가 큰 경로는 주차 중 화면 확인이 추가로 필요합니다.
5. 주행 중에는 `안내 반복`/`repeat`, `안내 종료`/`stop navigation`을 사용할 수 있습니다. 새 목적지·결과 선택·안내 시작·언어 변경은 주차 확인 후 가능합니다. 마이크 권한이 미리 허용되지 않았다면 주행 중 새 권한 창을 열지 않습니다.

한 번의 버튼 입력에 한 문장을 받습니다. **상시 듣기·호출어 감지·무조작 완전 핸즈프리는 구현하지 않았습니다.** 차량 스티어링휠 음성 버튼/Pleos 연동은 별도입니다. 음성은 플랫폼의 인식 서버에 전송될 수 있으며 앱은 녹음·검색어·목적지를 영구 저장하지 않습니다. 기록하는 것은 선택한 언어 설정뿐이며 개인 데이터 초기화로 지웁니다.

공통 명령 해석은 한국어·영어와 일부 스페인어·프랑스어·독일어·일본어·중국어·아랍어·러시아어 짧은 명령을 포함합니다. 모든 언어의 자유로운 대화를 해석하는 기능은 아닙니다. 다른 언어에서도 목적지는 선택 언어로 인식을 요청할 수 있고, 번호 숫자와 영어 공통 명령을 사용할 수 있습니다. 일반 CabinOS 어시스턴트는 기존 한국어 명령 기능을 유지합니다.

## 언어 범위

내장 길 안내 번역 **31개 언어/지역 팩**:

`ar`, `ca`, `da`, `de`, `en`, `eo`, `es`, `es-ES`, `fi`, `fr`, `he`, `hu`, `id`, `it`, `ja`, `ko`, `my`, `nl`, `no`, `pl`, `pt-BR`, `pt-PT`, `ro`, `ru`, `sl`, `sv`, `tr`, `uk`, `vi`, `yo`, `zh-Hans`.

- 회전·진입/출구·합류·갈림길·회전교차로·도착 문구와 거리 음성 문장을 오프라인으로 생성합니다. 도로명은 원문을 유지합니다.
- 인식 언어는 BCP 47 코드로 지정할 수 있습니다. 예: `ko-KR`, `en-US`, `fr-FR`, `hi-IN`. 브라우저는 기기가 보고한 TTS 언어도 목록에 표시하고 Android는 기기 음성 엔진의 보고 언어를 표시합니다. 보고된 TTS 언어와 STT 지원은 서로 다릅니다.
- 지역 변형은 기본 번역으로 연결합니다. 번역이 없는 언어는 **영어 안내로 대체한다고 명시**합니다. 예: `hi-IN` 인식 요청 + 영어 길 안내. `zh-Hant`도 현재 영어 대체이며 번체 중국어 번역을 지원한다고 표시하지 않습니다.
- 선택 언어는 검색 HTTP 헤더와 Nominatim `accept-language` 매개변수에 함께 적용합니다. 언어별 캐시를 구분하며 이전 요청을 취소합니다.
- TTS 음성이 없거나 인식 언어가 지원되지 않으면 설치/설정·화면 안내를 보여줍니다. 한국어 문구를 외국어 음성으로 읽는 식으로 언어 지원을 대신하지 않습니다.
- 이 범위는 전 세계 모든 언어·방언·상호 발음·교통 규칙·모든 도로 지원을 보장하지 않습니다. 앱 전체 UI·오류 안내·일반 어시스턴트는 한국어이며 내비게이션의 회전 문구와 음성/검색 언어를 변경합니다.

번역 출처는 BSD-2-Clause `osrm-text-instructions@0.15.0`입니다. [라이선스와 재생성](../third_party/osrm-text-instructions/README.md). 번역 팩은 31개지만 지역 중복이 있어 서로 다른 언어 수와 동일하지 않습니다. 회전교차로 출구 1~10은 번역 서수를 사용하며 11 이상은 일반 안내에 `#번호`를 함께 표시합니다.

## 오류·수명·안전 처리

- 녹음은 한 문장 또는 최대 30초로 제한합니다. 취소·화면 이탈·개인 데이터 삭제 시 종료합니다.
- 이전 녹음의 늦은 콜백은 구독 번호로 폐기합니다. 중간 인식 결과와 낮은 신뢰도 결과는 목적지로 사용하지 않습니다.
- 권한 거부·마이크 부재·서비스 미지원·언어 미지원·네트워크 오류·무응답을 검색어로 전달하지 않습니다.
- GPS 정확도/만료·현재 위치와 경로의 연결·차량 접근 지점 확인은 기존 조건을 유지합니다. 음성 시작이 검증을 건너뛰지 않습니다.
- 안내 음성과 마이크가 서로 겹치지 않도록 입력 중 안내 발화를 중단합니다. 음성 기능이 목적지를 자동 선택하거나 즉시 출발시키지 않습니다.

- 코어 **93개**, Android **54개**, 총 **147개**. 언어 31팩의 방향/유형/회전교차로 조합, 원래 좌표 유지, 언어 대체, 명령 구분, Android 실제 SpeechRecognizer API Intent/콜백·권한 거부·오류·타임아웃·배경 전환·언어 저장·주행 제한 검사.
- 새 Chromium 음성 검사 **14개**: 마이크 API 콜백에서 검색/번호/시작까지 실행, 주행 제한, 언어별 실제 렌더링·TTS 디스패치·요청 헤더, 복원/초기화, 인식 실패/늦은 콜백/낮은 신뢰도/타임아웃/모바일 배치. [결과](../test-fixtures/validation/voice-navigation-results.json).
- 기존 GPS 검사 **15개**도 통과했습니다. 전체 회귀의 최종 결과는 [검증 문서](VALIDATION.md)를 기준으로 확인합니다.
- [현재 실제 외부 지도·주소·경로 요청](../test-fixtures/validation/voice-review-live-providers.json)은 OSM·Nominatim·OSRM 모두 HTTP 200입니다. 음향 인식·실기기 GPS 결과가 아닙니다.
- 공개 배포는 [상태 및 필요한 저장소 설정](WEB_DEMO.md)으로 구분합니다. APK 다운로드 성공과 공개 사이트 배포 성공은 별도입니다.

```bash
source scripts/env.sh
./scripts/package-submission.sh
./scripts/build-web.sh
# 별도 터미널: python3 scripts/serve-web.py --directory build/site
node scripts/web/verify-voice-navigation.cjs
```

현재 0.10.0 지도 부하 시험은 CPU 4배 감속·10만 지점 경로·120개 합성 GPS 입력에서 초기 처리 628ms, p95 8.8ms, 최대 17.5ms였습니다. 실기기 FPS·네트워크 지연을 의미하지 않습니다. [측정](../test-fixtures/validation/map-performance-v0100.json) · [모바일 음성 복구 UI](screenshots/voice-mobile.png).

실제 Chromium에서도 TLS 검증을 유지한 OSM 타일·Nominatim 검색·OSRM 경로·확대/축소·드래그·안내 시작을 통과했습니다. [네트워크/조작 기록](../test-fixtures/validation/voice-review-live-browser.json) · [현재 화면](screenshots/voice-review-live-guidance.png). GPS는 공개 장소의 합성 좌표입니다. 환경 재시작으로 바뀐 기존 OS 공개 CA가 Chromium에 반영되지 않던 문제는 인증서 내용별 이름으로 등록하도록 시작 스크립트를 수정해 해결했습니다. TLS 검증을 끄지 않았습니다.

선택적 검색 게이트웨이도 언어 매개변수와 캐시를 언어별로 구분하도록 보완했으며 Python 검사 10개가 통과했습니다. 카카오 실서버 키·운영 HTTPS 서버 배포는 별도이며 Nominatim 언어 요청 전달과 구분합니다.
