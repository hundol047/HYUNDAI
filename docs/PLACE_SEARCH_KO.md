# 가게 검색과 경로 검증 · 0.7.0

EchoRoad 내비게이션에서 상호·지점·도시·주소 또는 `위도,경도`를 입력합니다. 기본 검색은 국가 제한이 없습니다. **전 세계 모든 가게의 등록이나 모든 출발지·목적지의 자동차 경로를 보장하지 않습니다.** 공개 데이터의 누락·별칭·도로 연결·국경·서비스 상태에 따라 결과가 달라집니다.

## 사용법

1. 안전한 주차 상태에서 **네비**를 엽니다. `스타벅스 판교`, `Café de Flore Paris`처럼 지역을 함께 입력하면 지점을 구분하기 쉽습니다.
2. 결과의 실제 이름·주소·분류·출처를 확인합니다. 제공자가 등록한 경우 전화·영업시간·HTTPS 상세 링크도 표시합니다. 등록 영업시간은 **현재 영업 중이라는 뜻이 아닙니다.** 같은 좌표의 서로 다른 가게를 하나로 합치지 않습니다.
3. **내 위치 주변 20km**는 정확하고 최신인 GPS가 필요합니다. 결과를 거리순으로 정렬하고 반경 밖 결과는 제외합니다. 기본 전 세계 검색과 구분되며 한국만 검색하도록 바꾸지 않습니다. 날짜 변경선의 검색 영역은 나누어 요청합니다.
4. **다른 결과 더 보기**로 6개씩 최대 18개까지 확인합니다. 자동완성·전수 수집을 하지 않습니다. 공급자 결과가 적거나 ID가 중복되면 더 보기가 종료될 수 있습니다. 검색 결과는 전체 매장 목록이 아닙니다.
5. 가게를 선택하면 GPS 없이도 반환된 실제 좌표에 핀을 표시합니다. 자동차 경로는 온라인 연결과 정확한 출발 GPS가 필요합니다. 실패했을 때 직선 경로나 가짜 GPS를 만들지 않습니다.
6. 경로의 출발 도로가 요청 GPS에서 1km를 초과해 떨어진 응답은 거부합니다. 미리보기가 있어도 최신 GPS가 출발 도로의 `max(45m, 정확도×2)` 안에 있어야 안내를 시작합니다. 이 사이 진입도로를 자동으로 안내하지 않습니다. 목적지와 도로 접근 지점 차이도 표시하고 100m 초과 시 확인을 받습니다.
7. 못 찾으면 지점·도시·현지어를 바꾸거나 **Google Maps에서 추가 검색**을 이용합니다. 이 버튼은 외부 서비스 검색 링크이며 Google Places API 연동이나 앱 내부 Google 경로 안내가 아닙니다.

주행/안내 중 검색·외부 링크·복잡한 지도 조작을 잠급니다. 지도 확대/축소·이동과 테마 변경은 정차 중 사용할 수 있습니다. 위치를 받았다고 차량의 P 상태를 추정하지 않습니다.

`스타벅스`만으로 반경 검색했을 때 제공자는 영역 안이지만 원형 20km 밖인 서울 결과 하나를 반환했습니다. 앱은 이를 제외했습니다. `스타벅스 판교`로 지역을 명시한 다음 검색은 성공했습니다. 검색어별 결과 누락을 데이터가 있는 것처럼 채우지 않습니다.

## 자체 검색 서버와 카카오 Local

기본 앱은 API 키 없이 OSM/Nominatim과 OSRM을 사용합니다. 공개 서버는 체험용이며 동시 사용자가 늘면 자체·계약 서버가 필요합니다. 별도 [선택적 검색 서버](../server/README.md)는 Nominatim 호환 응답과 카카오 Local 키워드 검색 어댑터를 제공합니다. **키가 등록된 서버에서 한국의 명시적 주변 검색에만** 카카오를 사용하고 전 세계 검색은 Nominatim으로 유지합니다. 카카오 제공자의 지점명·주소·분류·전화·상세 링크를 동일 UI로 표시합니다.

현재 상용 API 계정/키가 없어 **카카오 실서버는 미검증**입니다. 어댑터의 응답 변환·15개 공급자 페이지와 6개 앱 페이지의 경계·키 비노출은 프로토콜 fixture로 검사했습니다. Google Places 어댑터는 제공하지 않습니다. 외부 지도 링크와 구분해 주세요. 카카오 공식 문서 접근은 현재 클라우드 CONNECT 403으로 차단되어 운영 전 최신 문서·이용 조건·허용량을 추가 대조해야 합니다.

자체 서버의 실제 Nominatim 중계는 인증을 포함한 로컬 HTTP 통합 요청에서 성공했습니다. [근거](../test-fixtures/validation/place-gateway-live.json). 이는 공용 HTTPS 서버의 배포/24시간 운영이나 카카오 성공을 뜻하지 않습니다. 앱의 서버 접근키는 공급자 REST API 키와 다르며, 검색 서버에만 전송하고 파일/설정에 저장하지 않습니다.

## 재현

```bash
python3 -m unittest discover -s server -v
source scripts/env.sh
./gradlew :core:test :app:testDebugUnitTest
./scripts/build-web.sh
# 다른 터미널에서 python3 scripts/serve-web.py --directory build/site
node scripts/web/verify-place-search.cjs
# 아래 두 명령만 실제 제공자에 소량 요청합니다. CI에서는 실행하지 않습니다.
python3 scripts/check-places-live.py
node scripts/web/verify-place-search-live.cjs
```

CI의 `shop-live` fixture는 이 작업에서 보관한 실제 공개 응답의 **재생**이며 새로운 실서버 검사와 다릅니다. 별도 차량·교통·차선 데이터와 상점 폐업/현재 영업 여부는 검증하지 않습니다.
