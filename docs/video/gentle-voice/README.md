# 부드러운 한국어 안내 비교

퓨처랩스 · 2026-10-27 한국시간

같은 APK에서 “약 삼백 미터 앞에서 우회전해 주세요”를 실제로 재생했습니다. A/B는 별도 설치한 sherpa-onnx TTS Engine 1.13.8 / Supertonic 3의 프리셋 0/2입니다. 두 음색 중 편안하게 들리는 것을 비교할 수 있습니다.

| 음색 | 바로 듣기 | 전체 실행 영상 |
| --- | --- | --- |
| A · 프리셋 0 | [실제 앱 음성](a/voice-sample.m4a) | [소리 포함 영상](a/execution.mp4) |
| B · 프리셋 2 | [실제 앱 음성](b/voice-sample.m4a) | [소리 포함 영상](b/execution.mp4) |

전체 영상은 Android 13 에뮬레이터의 연속 화면과 실제 출력 음성입니다. 영상·음성 패킷이 원본과 같은지 확인했습니다. 듣기 파일은 해당 녹음에서 앞뒤 대기 구간만 줄인 하나의 연속 발췌입니다. 대체 내레이션을 붙이지 않았습니다.

앱 기본 속도는 0.94배이며 엔진 음높이는 변경하지 않습니다. 앱의 **설정 → 목소리 골라 듣기**는 Android TTS에 공개된 설치 목소리를 표시합니다. 녹화 엔진의 세부 프리셋은 엔진 자체 설정에서 선택했습니다. 이 엔진과 모델은 APK에 포함되지 않으므로 휴대폰에서 같은 음색이 자동으로 나오는 것은 아닙니다. [설정·출처·라이선스](../../NATURAL_VOICE_KO.md)

- 두 음성 모두 자동 전사에서 “약 300m 앞에서 우회전해주세요.”로 확인됐습니다. 자동 전사가 편안함·자연스러움을 보증하지는 않습니다.

- 실제 삼성 S20+ 스피커나 Pleos 기기 녹화가 아닙니다. 각 폴더의 evidence.json, speech-analysis.json, voice-selection.json, SHA256SUMS에 검증 범위를 남겼습니다.
