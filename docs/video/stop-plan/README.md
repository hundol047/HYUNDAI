# 정차 플랜 실제 APK 실행 영상

[실행 영상 보기·다운로드 (MP4, 2분 49초)](CabinOS_ONE_stop_plan.mp4) · [실행 증거](evidence.json) · [검토 결과](review.json) · [세로 화면](phone-portrait.png)

일반 Android 13(API 33) 에뮬레이터에 휴대폰 검토 APK를 설치해 `adb shell screenrecord`로 연속 녹화합니다. 사진 슬라이드나 브라우저 구현이 아닙니다. 차량 속도·기어·충전은 앱 데모 데이터이며 Pleos 실차 검증은 아닙니다. 녹화에 음성 트랙은 포함하지 않습니다.

영상에서 확인하는 동작:

1. 주행 시 정차 기능 잠금, P 주차 확인 후 계획 설정
2. 30분 빠른 출발 설정과 45분 계획 변경
3. 25분 집중 시작 및 첫 화면의 큰 세션 버튼·배경 소리 조작부 표시
   - 소리 선택 후 설정 창을 닫고 한 번에 소리 끄기
4. 계획을 넘기지 않는 5분 연장
5. 충전 15분으로 변경 후 안전 일시정지·명시적 재개, 세션 단축 및 추가 연장 차단
6. D 기어·속도 0인 신호 대기의 잠금 유지
7. 정차 복귀

휴대폰 세로 배치는 해상도 변경 후 별도 스크린샷으로 확인했습니다. 가로 녹화 영상에는 포함되지 않습니다.

첫 실행에서 계획 카드가 집중 조작부를 아래로 밀어내는 점을 발견해, 진행 중인 세션을 계획 카드보다 먼저 표시하도록 수정했습니다. 재개 시 초 단위 반올림으로 생기는 1초 여유가 연장 버튼을 켜는 문제도 발견해 1분 이상 여유가 있어야 연장하도록 수정했습니다. 수정 후 전체 테스트 364개(핵심 162, Android 202)·정적 검사·SDK 포함 검토 APK 빌드를 통과했습니다. 자동 검사 통과는 모든 기기·실차 환경에서 오류가 없다는 보장은 아닙니다.

원본 연속 영상과 실행 증거를 이 폴더에 보관합니다. APK 실행 시나리오 10개가 통과했고 영상 전체 디코딩 오류는 0개입니다. `evidence.json`의 APK SHA-256으로 설치본을 대조할 수 있습니다.

추가 개선: [간단한 조작·재개 오류 수정](../../SIMPLE_CONTROLS_KO.md). 소리 중지는 선택 상태·명령 결과로 검사했으며 녹음이 없으므로 실제 스피커 음질·출력 검증은 아닙니다.
