# 실제 자연음 출처

원본의 앞 20초를 모노 22050Hz PCM으로 변환하고 음량 정규화 및 양 끝 페이드를 적용했습니다. 원본과 파생 음원은 아래 라이선스를 따릅니다.

빗소리는 반복할 때마다 끊기는 느낌을 줄이기 위해 시작 무음 약 0.577초를 제거하고 시작 10ms 페이드를 다시 적용했습니다. 백색 소음·잔잔한 톤은 합성음이며, 녹음 자연음과 전환할 때 음량이 크게 뛰지 않도록 재생 게인을 0.4로 낮췄습니다. 마음이 편안해지는 효과나 실제 스피커 음량을 보장하는 조정은 아닙니다.
