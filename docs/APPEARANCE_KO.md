# 실내 맞춤 화면 색상 (0.5.0)

주차/충전 상태에서 **설정 → 실내에 맞춘 화면 색상**을 엽니다. 그래파이트·웜 샌드·모카 우드·세이지·미드나이트 중에서 차량 실내와 어울리는 어두운 배경을 고르고, `#RRGGBB` 강조색을 직접 입력할 수 있습니다. 과도하게 어두운 강조색은 버튼과 글자를 읽을 수 있도록 밝게 보정하며 실제 표시 색을 함께 보여줍니다. 위험 경고의 빨강·주황과 텍스트/아이콘 의미는 유지합니다.

- 텍스트·보조 글자·강조색 버튼의 대비를 공통 Kotlin 색상 계산에서 최소 4.5:1로 검사합니다. 화면 장치·햇빛·개인별 피로도에 대한 실제 인체 실험을 뜻하지는 않습니다.
- 시스템/편안한/야간 밝기를 고를 수 있습니다. Android는 앱 창 밝기만 각각 시스템 설정/60%/25%로 적용합니다. 시스템 전체 밝기나 차량 실내 조명 권한을 요청하지 않습니다. 브라우저는 색상 명도를 조절하며 기기 백라이트를 제어하지 않습니다.
- 야간 지도는 지도 타일에만 필터를 적용합니다. 경로선·핀·경고·출처 표시는 별도 레이어이며 어둡게 반전하지 않습니다. 지도 데이터를 바꾸거나 경로를 재계산하지 않습니다.
- Android는 시각 설정을 SharedPreferences에, 브라우저는 `cabinos.appearance.v1` localStorage 키에 저장합니다. 저장된 값은 프리셋·강조색·밝기·야간 지도뿐이며 GPS·목적지를 보관하지 않습니다. 개인 데이터 초기화 시 색상 설정도 초기화됩니다.
- 주행/D 기어 정지/안내 활성화/상태 미확인 중에는 설정 진입과 색상 변경을 제한합니다. 웹의 직접 변경 API도 같은 주차 조건을 확인합니다. 저장한 시각 설정 복원은 차량 주차 신뢰를 만들지 않습니다.

Android Compose 화면 변경·창 밝기 속성·저장 복원을 검사하고, 브라우저에서 프리셋·잘못된 색·어두운 강조색 보정·새로고침·위치 없는 복원·주행 제한·야간 타일 레이어·모바일 폭을 검사합니다. [실제 Android UI 렌더링](screenshots/appearance.png)을 볼 수 있습니다.
