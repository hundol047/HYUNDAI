# 장소별 사진 표시

카페·식당·산책·쇼핑 목록의 같은 업종 사진 반복을 제거했습니다. 사진이 없는 곳을 다른 장소 사진으로 채우지 않습니다.

## 확인 순서

1. 해당 OSM 객체의 Wikimedia Commons 파일·image 참조.
2. 해당 객체에 연결된 Wikidata의 P18 사진. P625 좌표가 장소 기준 300m 이내여야 합니다. 브랜드의 Wikidata는 사용하지 않습니다.
3. 해당 객체의 Wikipedia 문서 사진. 문서의 지구 좌표가 300m 이내여야 하며 Commons 라이선스가 있어야 합니다.
4. 참조가 없으면 Wikidata 이름 검색 최대 3건. 정규화한 이름/별칭 일치, 물리적 장소 유형, 300m 이내 좌표, P18 사진을 모두 만족해야 합니다. 영화·회사·브랜드 결과는 제외합니다.

Commons가 반환하는 공식 `thumb.wikimedia.org`와 기존 `upload.wikimedia.org`를 HTTPS·정해진 경로로만 허용합니다. 이전 코드는 새 공식 호스트를 거부해 사진이 있어도 대표 이미지로 대체했습니다. 이미지 용량·크기를 제한하고 원본 저작자·라이선스·출처를 함께 표시합니다.

장소명·좌표를 포함한 키로 10분간 조회 결과를 메모리에 보관하고 동시에 두 장소까지만 확인합니다. 이 조회는 화면에 들어오는 항목에서 수행됩니다. 개인정보 초기화 시 메모리 캐시도 삭제합니다. 이름 검색 시 장소명이 Wikidata에 전달되며, 위치는 다운로드한 문서의 좌표와 앱 안에서 대조합니다.

## 검증과 제한

- [공개 원본 HTTP 조회 결과](PLACE_PHOTO_SOURCES.json): 카페 2곳·공원 2곳의 서로 다른 파일을 HTTP 200으로 받았습니다. OSM 연결 대상과 사진 좌표를 대조했으며 라이선스를 확인했습니다. 네 곳의 표본 검증이지 전 세계 모든 장소 사진 검증은 아닙니다.
- 실제 원본 사진을 확인하지 못하면 ‘실제 장소 사진 미확인’을 표시합니다. 지원 편의점의 브랜드 로고는 지점 사진이 아니라고 명시합니다. 데모의 가상 장소는 실제 사진 조회 대상이 아닙니다.
- Commons에 일반 소규모 매장 사진이 모두 있지는 않습니다. 네이버 이미지 무단 수집, 다른 지점 사진, 이름만 비슷한 검색 사진으로 대체하지 않습니다. 모든 매장 사진 제공에는 적법한 장소 사진 공급원/권한과 추가 연동이 필요합니다.
- 공개 자료 사진은 촬영일이 과거일 수 있어 현재 영업 여부·외관을 보장하지 않습니다. 300m 검증은 공개 좌표 오차를 위한 범위이며 동일 건물의 지점 구분은 원본 등록 정확도에도 의존합니다.
- Android 에뮬레이터 녹화는 실제 APK 화면입니다. 시연 위치와 차량 상태는 모의 입력이며 실제 차량·휴대폰 GPS 검증이 아닙니다.
