# 서울시청 → 연세대학교 미래캠퍼스 · 0.10.2

2026-10-23 실제 Chromium에서 검색·경로 계산·안내 시작·합성 GPS 이동·도착까지 두 번 실행했습니다. 최종 실행은 수정된 0.10.2입니다. **지도·상호·자동차 경로는 실제 OSM/Nominatim/OSRM 응답이고 GPS와 시계는 시험 입력입니다. 실차 또는 Android 실기기 주행 시험이 아닙니다.** Android와 브라우저는 같은 Kotlin 내비게이션 계산을 사용합니다.

53곳의 점검에서 화면과 겹치는 모든 타일의 이미지 디코딩·불투명 표시를 확인했습니다. 중간의 1Hz 합성 위치는 모두 공유 추적기에 입력했고, 지도 화면 갱신과 타일 요청은 점검 지점으로 제한했습니다. **113km의 모든 화면 프레임·모든 옆 도로를 검사한 결과가 아닙니다.** 지도 영역을 미리 내려받거나 오프라인 지도로 수집하지 않았습니다. 합성 이동 속도는 교차로 주변 5m/s, 일반 구간 12m/s, 고속도로 표기 구간 25m/s인 시험 조건이며 실제 제한속도를 측정하거나 운전 속도를 권고하는 값이 아닙니다.

## 실제 누락을 찾아 수정한 내용

**1. 붙여 쓴 지역명 때문에 검색 결과가 비던 경우.** 실제 `스타벅스 원주무실`은 0건, `스타벅스 원주 무실`은 무실동 실제 결과 2건이었습니다. 원문 결과가 비었을 때만 한국 도시명과 이어 붙인 지역명을 공백으로 분리해 **한 번** 재검색하도록 Android·웹을 함께 수정했습니다. 모든 문자를 유지하고 도시·지점 단어를 삭제하지 않습니다. 원문 검색어 입력창은 유지하며 보정 검색어와 각 주소를 표시합니다. 두 실제 응답 주소는 서원대로 178 무실동과 능라동길 무실동이었습니다.

이 보정은 여러 단어로 입력한 검색어의 마지막 지역명에 한정됩니다. 모든 한국어·세계 언어의 지점명 정규화 기능이 아닙니다. 원문 결과가 있으면 재검색하지 않고, 서버 오류를 빈 결과로 바꾸지 않습니다. 더 보기에서는 보정 검색어와 이전 ID 제외 조건을 유지하고, 취소·주행 전환 뒤 도착한 응답은 무시합니다. 관련 공통·Android·브라우저 회귀 검사를 추가했습니다.

**2. 이름 없는 진출로에서 방향 표지가 빠지던 경우.** OSRM 응답에는 `19: 남원주, 충주, 강원 혁신도시`가 있었지만 기존 파서가 도로 이름만 읽어 안내에 반영하지 않았습니다. 두 플랫폼 모두 `destinations`를 보존하고 도로명과 함께 표시하도록 수정했습니다. 도로명·방향 표지가 모두 없으면 제공자 도로 번호를 사용합니다. 직접 이름을 만들지 않습니다. 수정 후 같은 경로에서 남원주IC와 미래캠퍼스 분기 표지가 화면 안내에 나타나는 것을 확인했습니다. 실제 경로 응답을 Android 회귀 fixture로도 보관했습니다.

**3. 도착 후 남던 주행 잔여 거리.** 도착 판정 뒤 이전 이동의 잔여 거리를 계속 보여주던 부분을 숨기고 차량 경로 도착과 실제 목적지 접근 거리 안내를 유지했습니다. 아직 주행 중에는 남은 거리를 정상 갱신합니다.

## 가게 누락은 0이라고 판정할 수 없음

| 실검색 | 관찰 결과 |
|---|---|
| 스타벅스 원주무실 | 원문 0건 → 공백 보정 후 무실동 결과 2건 |
| 우리은행 연세대미래캠퍼스 | 출장소 1건. 실제 이름·연세대길 1 주소·전화·등록 영업시간 응답 확인 |
| 이디야 매지리 | 0건. 가게의 실제 존재/현재 영업 여부 또는 데이터 미등록 여부를 확정하지 않음 |

**현재 데이터로 미등록 가게까지 포함한 전체 가게 누락 0을 보장하지 않습니다.** 검색 결과가 없다는 사실을 가게가 없다는 뜻으로 바꾸거나 가짜 장소로 메우지 않았습니다. 지도 타일도 확대 수준과 가시 범위에 따라 상호명을 생략하므로 검색 가능한 장소가 모든 배율에 이름으로 보이는 것은 아닙니다.

캠퍼스 입구 주변의 작은 범위로 Overpass를 재확인했지만 16초 시간 초과였습니다. 검색 색인과 직접 대조하기 위한 별도 소규모 OSM map API 요청은 이 환경의 프록시가 CONNECT 403으로 차단했습니다. 이 독립 대조는 완료하지 못했으며 다른 호스트로 우회하지 않았습니다. 따라서 전체 실제 가게 목록과 검색 결과를 완전히 대조했다는 보고가 아닙니다. 운영용 카탈로그 보완은 적법하게 제공받는 상용/공공 데이터와 자체 서버가 필요하며 기존 선택적 Kakao 게이트웨이는 실제 계정 키가 없어 실서비스 검증이 남아 있습니다.
