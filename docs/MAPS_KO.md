# 주변 지도·장소 추천 (0.3.0)

Android 앱과 브라우저 데모에 지도 화면을 추가했습니다. 기존 EchoRoad의 그림 경로는 여전히 시뮬레이션이며, 정차 중 주변 지도의 기능과 구분합니다.

## 사용 순서

1. 데모에서 주차/충전을 선택하고 P 상태 확인을 기다립니다. 왼쪽 `지도` 또는 추천 카드의 `지도에서 보기`를 엽니다.
2. 첫 화면은 **판교 체험 기준점**과 **예시 장소 핀**입니다. 현재 차량 위치나 실제 매장이라고 표시하지 않습니다.
3. `내 위치 사용`으로 기기 위치 권한을 요청하거나, 지도를 이동한 뒤 `지도 중심 사용`으로 기준점을 정합니다. 실제 GPS가 없거나 권한이 거부되면 위치를 만들어내지 않습니다.
4. `주변 검색`을 누르면 기준점 반경 1.2km의 OpenStreetMap 등록 카페·식당·공원·상점을 Overpass에서 요청합니다. 빈 결과나 오류를 가짜 장소로 대체하지 않습니다.
5. 지도 핀이나 목록을 고르고 `이 장소로 계획`을 누릅니다. 왕복 이동·출발 준비 시간을 공유 일정에 반영합니다. 실제 보행 경로·영업 여부는 `외부 지도`에서 확인합니다. Android 시스템 알림은 선택한 장소의 복귀 도보 시간까지 출발 준비 여유에 더해 앞당겨 예약합니다. 기기 절전 정책으로 지연될 수 있습니다.

파란 핀은 기준점, 초록 핀은 시간 내 추천 가능, 주황 핀은 시간 부족입니다. `전체/카페/식당/산책/쇼핑` 필터는 지도·목록·공유 추천 엔진에 함께 적용됩니다.

## 데이터와 시간 계산

- Android 지도: osmdroid 6.1.20, OpenStreetMap MAPNIK 타일. 브라우저: Leaflet 1.9.4를 로컬 번들로 제공하며 같은 타일 서버를 사용합니다. API 키가 필요하지 않습니다.
- 지도: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`. 장소: `https://overpass-api.de/api/interpreter`. 출처 표시와 앱 User-Agent를 사용하고 타일 일괄 다운로드·사전 수집을 하지 않습니다. Android 다운로드 동시 요청은 2개로 제한합니다.
- 장소 조회는 사용자 버튼으로만 시작하며 최소 30초 간격, 최대 60개 결과, Android 연결 12초·읽기 18초, 브라우저 전체 18초 제한입니다. 응답 크기·잘못된 좌표·2km 밖 결과·중복 ID·이름 없는 항목을 검사합니다.
- 도보 시간은 **직선거리 × 1.4 ÷ 1.1m/s**, 분 단위 올림 추정입니다. 실제 길찾기 결과가 아닙니다. 횡단보도·출입구·하천·건물 통로·보행 제한은 반영하지 않습니다.
- 이름·좌표는 OSM 등록 데이터이며 현재 영업·혼잡도·예약을 보장하지 않습니다. 지도와 장소 검색은 인터넷 연결이 필요합니다.

## 안전·위치 처리

주행·D 기어 신호 대기·신호 미확인에서는 지도 화면 진입과 장소 계획 적용을 제한합니다. 조회 중 주행으로 바뀌거나 앱을 벗어나면 요청을 취소하고 늦게 도착한 결과를 적용하지 않습니다. 개인 데이터 삭제는 메모리에 보유한 검색 기준점도 초기화합니다.

실제 기기 위치는 명시적 버튼과 OS 권한으로 얻으며 60초 이내·정확도 1km 이내 위치만 사용합니다. 실제 위치가 있어도 차량 P 상태를 증명하지 않습니다. 위치 좌표는 설정·Room DB에 저장하지 않습니다. 지도 SDK는 화면에 요청한 타일을 앱 전용 캐시에 보관할 수 있습니다. 주변 검색 시 기준점 좌표가 Overpass에, 지도 표시 시 해당 영역이 OSM 타일 서버에 전달됩니다. 위험 공유 동의 토글과 별도의 지도 서비스 요청입니다.

## 이번 환경에서 검증한 범위

공유 엔진의 거리·시간·계획·주행 제한, Android Compose 지도 생성과 계획 선택, Overpass 응답 파싱, 브라우저의 마커·카테고리·권한 거부·늦은 응답 차단·빈 결과·오프라인·모바일 배치를 검사했습니다. 프로토콜 검사는 **합성 테스트 응답**을 사용하며 실제 서버 조회 결과로 표기하지 않습니다.

현재 클라우드 프록시는 OSM 타일·Overpass·정책 페이지 접속을 HTTP CONNECT 403으로 차단합니다. 필요한 호스트를 환경 설정 초안에 추가했으며 아직 적용되지 않았습니다. 따라서 실제 지도 타일 다운로드·실서버 장소 검색과 GPS 기기 실행은 **검증 미완료**입니다. 녹화와 UI 렌더링에 보이는 빈 지도/핀은 이 제한을 명시합니다. 연결이 허용된 Android 기기/브라우저에서 추가 확인해야 합니다.

## 0.5.0 연결 재검사

같은 프록시 경로에서 OSM 타일과 글로벌 내비게이션 Nominatim/OSRM 요청은 HTTP 200으로 바뀌었고 실제 브라우저 표시를 확인했습니다. 별도 주변 POI 제공자인 Overpass는 이 검사에서 HTTP 502와 시간 초과가 발생했습니다. 이를 실데이터 장소 추천 성공으로 표시하지 않습니다. 장소 검색이 실패하면 기존 예시/결과의 출처를 유지하고 오류를 표시합니다. 야간 지도와 화면 테마는 APPEARANCE_KO.md를 확인하세요.
