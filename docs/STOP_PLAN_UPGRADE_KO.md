# 정차·충전 핵심 기능 개선

CabinOS ONE의 StopSense(시간 관리)와 CabinOS(집중·휴식)를 같은 출발 계획에서 연결합니다.

- 세로 휴대폰과 가로 차량 창에 공통 ‘나의 정차 플랜’을 표시합니다.
- 시간이 미설정이면 15·30·60분 뒤 출발 버튼을 제공합니다. 차량 충전 예상과 사용자 계획 중 더 이른 제약을 유지합니다.
- 계획이 있으면 활동 마감·출발 시각, 활동·왕복 이동·출발 준비 시간, 현재 계획 근거를 표시합니다. 시각은 기기 시간대 기준입니다.
- 활동 여유가 15분 이상이면 기본 집중 시간, 미만이면 기본 휴식 시간을 제안합니다. 실제 여유보다 긴 세션은 제안하지 않습니다. 선호도 학습이나 건강 상태 추정이 아닌 시간 기반 추천입니다.
- 장소를 선택했다면 왕복 시간을 유지합니다. ‘차 안에서 보내기로 변경’으로 명시적으로 취소할 수 있습니다. 도보 시간은 추정이며 실제 이동을 추적한 복귀 알림은 아닙니다.
- 진행·일시정지 세션에 ‘여유 안에서 5분 더’를 제공합니다. 실제 추가 시간은 남은 여유 및 세션 총 120분 한도 중 작은 값입니다. 일시정지를 자동 해제하거나 출발 시각을 뒤로 미루지 않습니다.
- 유효한 정차 확인을 모든 시간 설정·시작·연장 동작에서 다시 검사합니다. 신호 만료·주행 상태에서는 연장할 수 없습니다.

## 검증 범위

`ContextEngineTest`에 출발·준비 시간 유지, 일시정지 상태·활동 기록 유지, 만료 신호 연장 거부 검사를 추가했습니다. `StopPlanPanelTest`는 360dp 세로 및 1024dp 가로 창의 표시·버튼 크기·추천 시간·잠금·장소 선택 보존을 검사합니다.

Robolectric 검사는 실제 차량 디스플레이·휴대폰 터치·오디오 시험을 대신하지 않습니다. 차량용 정차 전용 정책 및 기존 Pleos/AAOS 신호 안전 판정은 변경하지 않았습니다.
