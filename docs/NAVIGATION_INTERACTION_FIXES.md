# 지도 조작·음성·위치 수정

- 일반 Android의 확대 지도에서 드래그와 핀치 확대/축소를 지원합니다. 드래그 후 자동 중심 이동을 멈추고 ‘내 위치로’로 복귀합니다. Pleos 기본 내비 화면의 조작은 차량 OS가 제어합니다.
- GPS 추적 일시 중단 시 마지막 음성 안내 기록을 유지합니다. 동일한 회전/거리 구간의 진동은 30초간 중복 억제합니다. 명시적 반복 요청과 새 안내 시작은 기록을 초기화합니다.
- 정확한 GPS 또는 fused 위치가 최근 3초 이내이면 정확도가 두 배 이상 나쁜 보조 위치로 교체하지 않습니다. 실제 GPS의 부정확한 신호, 만료, 권한 상실은 계속 안내를 중지합니다. 타임스탬프를 갱신하거나 위치를 만들어내지 않습니다.
- 내비 활성 여부가 화면 선택을 덮어쓰던 조건을 제거했습니다. 하단 제한 기능은 터치 시 안전 잠금 이유를 알립니다. 안내 종료 및 안전한 정차 확인 전 지도·기록·설정 제한은 유지합니다.

실제 S20+ GPS 수신·주행·스피커 시험은 수행하지 않았습니다. 실내·터널 등에서의 GPS 정확도와 수신 자체를 소프트웨어로 보장할 수 없습니다.
