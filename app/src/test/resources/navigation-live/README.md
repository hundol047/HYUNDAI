# Recorded OSRM responses

These unmodified JSON responses were fetched through the session proxy from the public OSRM driving endpoint on 2026-10-22. They are deterministic regression fixtures after capture, not live CI requests or physical GPS evidence. Source request coordinates, payload hashes and observed HTTP results are recorded in docs/validation/live-navigation-results.json. Roads are © OpenStreetMap contributors (ODbL), https://www.openstreetmap.org/copyright . No individual user location is included: the inputs are predefined public city landmarks.
