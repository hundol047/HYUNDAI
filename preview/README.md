# CabinOS ONE 휴대폰 검토본

## 이번 수정

- 교통 중계 서버와 앱 연결 설정을 추가했습니다. 공급자 키는 서버에서만 사용하고 앱에는 별도 중계 접근 토큰을 입력합니다. 설정은 메모리에만 보관합니다.
- 현재 위치 인근 **한 도로 구간**의 속도 비율을 빨강·노랑·초록으로 표시하고 신뢰도가 낮으면 회색으로 표시합니다. 60초 조회, 90초 만료, GPS 불확실·백그라운드 시 제거/취소합니다. 전체 도로·진행 방향 매칭·정체 원인·교통 반영 ETA·우회 안내는 아닙니다.
- 공개 서버는 미배포이며 한국 요청은 서버에서 차단합니다. 따라서 설치 직후에는 교통 색상이 표시되지 않습니다. 로컬 서버에서 암스테르담 실제 API 응답 200을 확인했습니다. [교통 서버 실행·범위·검증](../server/TRAFFIC.md)

- 검색 입력창을 전체 너비로 표시하고 검색·내 위치 버튼을 바로 아래에 배치했습니다. 안내 중에는 지도 위에서 ‘안내 다시 듣기·안내 종료’를 바로 누를 수 있습니다(최소 높이 52dp).
- TomTom 키 인증은 확인됐지만 공개 중계 서버와 한국 데이터 조건은 미완료입니다. OSRM 도착 시간은 실시간 교통을 반영하지 않습니다. [실시간 교통 연결 요건](../docs/LIVE_TRAFFIC_INTEGRATION_KO.md)

- 주변 검색의 기기 위치를 최근 10초·오차 50m 이내로 제한했습니다. 누락된 정확도, 오래되거나 오차가 큰 위치는 사용하지 않습니다. 첫 데이터원의 결과가 비어 있으면 보조 검색을 시도합니다. 검색 시작 시 예시 장소를 비워 실제 결과와 섞이지 않게 했습니다. 실제 매장의 최신 영업 여부와 누락 여부는 공개 지도 데이터의 한계가 있습니다.
- 지도 연결 상태가 같을 때 불필요한 연결 설정과 타일 상태 검사를 반복하지 않습니다. S20+의 실물 프레임 속도·지도 서버 응답 시간 개선을 검증한 것은 아닙니다.

- 사진이 없는 CU·GS25·세븐일레븐·이마트24 장소는 이름으로 브랜드가 식별될 때 로고를 표시합니다. 실제 사진이 우선이며, ‘브랜드 로고 · 매장 사진 아님’으로 구분합니다. 미확인 브랜드는 업종 대표 이미지를 유지합니다.
- 지도 타일 메모리 캐시를 128개로 늘리고 매 프레임의 상태 검사를 최대 초당 2회로 줄였습니다. 미방문 지역의 서버 응답 시간을 보장하지는 않습니다.
- 화면 회전으로 Activity가 재생성될 때 집중 세션과 배경 소리를 유지합니다. 실제 앱 이탈·오디오 포커스 상실·안전 잠금에서는 계속 중지합니다.
- 피아노를 제거했습니다. 비·계곡·파도·새소리는 서로 다른 실제 녹음이며, 백색 소음·잔잔한 톤만 합성음입니다. 총 6종을 오프라인 재생합니다. [원본·저작자·라이선스](../docs/NATURE_AUDIO_CREDITS.md).

- 확대 지도에서 드래그·핀치 확대/축소를 지원합니다. 이동 후 자동 중심 복귀를 멈추고 ‘내 위치로’로 다시 추적합니다.
- GPS 품질 변화와 거리 경계에서의 같은 음성 반복을 억제합니다. 명시적 반복 요청과 위치 제공자 재연결 후 안내는 유지합니다.
- 내비 화면이 홈 선택을 덮어쓰는 문제를 수정했습니다. 하단 지도·기록·설정의 안전 잠금 중에는 터치 시 이유를 표시합니다. 안내 종료와 안전한 정차 확인 전 제한은 유지합니다.
- 최근 정확한 GPS/fused 위치보다 품질이 나쁜 보조 위치값에 대한 필터를 보완했습니다. GPS 만료·부정확·권한 상실 시 안내 중지는 유지합니다. [수정 범위와 제한](../docs/NAVIGATION_INTERACTION_FIXES.md)

- 내비 지도 터치 → 앱 창을 채우는 확대 지도 → ‘지도 축소’ 또는 뒤로가기로 복귀합니다. 세로·가로 레이아웃에서 검사했습니다. 확대/축소로 경로를 새로 시작하거나 종료하지 않습니다. GPS가 끊긴 경우 회전 안내를 표시하지 않고 위치 대기를 유지합니다.
- 이 확대 기능은 일반 Android의 앱 내 지도에 적용됩니다. 실제 Pleos 차량은 기존 NaviHelper 기본 내비 연동을 유지하며 기본 내비 창 크기는 차량 OS가 제어합니다.
- 사진: 장소의 원본 OSM 객체에서 사진 참조를 읽고, 해당 객체에 연결된 Wikidata 사진도 조회합니다. 브랜드 항목은 사용하지 않으며 좌표 일치를 검사합니다. 공개 사진이 없는 곳은 앱에 포함된 카페·식당·산책·쇼핑 대표 사진을 표시하고 ‘업종 대표 이미지 · 실제 장소 사진 아님’이라고 명시합니다. 네이버 사진 연동은 포함하지 않습니다.

- 안내 버튼이 멈춰 보이던 경우: 오래 멈춘 GPS 구독을 다시 연결하고, 기기의 `fused` 위치 제공자를 지원합니다. 원래 수신 시각이 10초 이내이고 정확도 기준을 만족하는 실제 기기 위치만 재사용합니다. 위치 대기·경로 계산·오류 메시지를 목적지 버튼 옆에 표시합니다.
- 주변 검색: Photon의 등록 장소 검색을 먼저 사용하고, 같은 지역의 최근 결과를 2분간 메모리에 유지합니다. 새 지역은 이전 지역의 30초 제한으로 막지 않으며 실패한 요청은 5초 이후 재시도할 수 있습니다. 일부 분류 실패는 완전한 검색 성공으로 캐시하지 않습니다.
- Android 내비 화면의 Google Maps 추가 검색 링크를 제거했습니다.

- 지도: 추천순(이용 가능 여부 → 가까운 순)으로 여러 장소를 스크롤합니다. 실시간 이용자 평점 순위가 아닙니다. 실제 검색은 분류별 최대 15곳, 예시는 분류별 4곳입니다. 실제 장소와 예시를 구분합니다.
- 휴대폰: 지도·추천 목록·펼친 상세 버튼을 하나의 목록에서 스크롤합니다. 차량 가로 화면은 지도와 목록의 나란한 배치를 유지합니다.
- 사진: 해당 장소에 등록된 Wikimedia Commons 사진을 저작자·라이선스와 함께 표시합니다. 사진·출처가 없거나 불러오지 못하면 구분 문구가 붙은 업종 대표 이미지를 표시합니다. 대표 이미지는 오프라인에서도 표시되며 [저작자·원본·라이선스](../docs/CATEGORY_IMAGE_CREDITS.md)를 제공합니다.
- 내비: 검색 결과 또는 선택한 목적지의 **현재 위치에서 안내 시작**을 누르면 정확한 GPS를 확인하고 앱 내부에서 자동차 경로를 계산해 안내합니다. 위치 권한 요청과 GPS 대기 후 연결을 포함합니다. 목적지 접근 거리가 큰 경우 기존 확인 절차를 유지합니다.
- 음성: ‘판교역 찾아 줘’, ‘판교역으로 안내해 줘’, ‘판교역까지 데려다줘’로 내비 화면을 열어 검색합니다. 동명이 있을 수 있으므로 주소를 확인하고 ‘1번’ 등 결과 번호를 말하면 해당 목적지로 안내합니다. 검색어를 화면에도 반영합니다.
- 검색: 최신 GPS가 있을 때 주변을 우선하되 국가를 제한하지 않습니다. GPS가 없으면 전 세계 검색 결과일 수 있으므로 주소를 확인해야 합니다.

## 검증과 제한

이번 공개 캠퍼스 좌표(37.279,127.908) 점검에서 Photon 카페 결과는 0곳, Overpass 두 서버는 20초 제한 시간 초과였습니다. 이 지역의 실제 카페 검색이 완성됐다고 검증하지 못했습니다.

core 149개 + Android 186개, 총 **335개 통과·실패 0·건너뜀 0**. 공식 SDK 포함 lint·phonePreview APK 빌드가 통과했습니다. [이번 수정의 검증 기록](runtime-fixes-verification.json)을 참고하세요. Robolectric 화면·위치·음성 콜백 검사는 실제 삼성 S20+의 마이크·GPS·스피커 시험을 뜻하지 않습니다. 공식 SDK를 포함해 컴파일했으며 공식 Pleos 기기 전체 시나리오 검증을 새로 수행한 것은 아닙니다.

이번 실제 HTTP 점검에서 판교 기준 Photon 검색은 카페·식당·산책·쇼핑 각각 15곳(HTTP 200)을 반환했고, OSRM 자동차 경로는 약 90.4km 경로(HTTP 200)를 반환했습니다. 이는 서버 점검이며 S20+ 실물에서 같은 경로를 주행한 결과가 아닙니다. Overpass의 502·시간 초과는 재현되어 보조 경로로 남겼습니다. 공개 서비스의 장애·미등록 매장·사진 누락은 가능하며 모든 지역의 수록을 보장하지 않습니다. 상용 장소 API 키는 설정되어 있지 않습니다.

기존 배경 소리·화이트/블랙 등 테마는 유지됩니다. 실제 교통·차선 안내는 제공하지 않습니다. 차량 기기에서는 정차 전용 정책을 유지합니다.
