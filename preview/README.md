# CabinOS ONE 휴대폰 검토본

퓨처랩스 · Android 10 이상 · `CabinOS ONE 테스트` (`io.cabinos.one.preview`, `0.11.1-preview`). 이번 수정본은 추천 목록·사진·현재 GPS 출발 안내·음성 연결을 개선한 Android 검토용 APK입니다. 기존 검토본과 같은 테스트 서명으로 업데이트 설치할 수 있습니다. 차량용 가로 배치와 안전 잠금 기준은 유지했습니다.

휴대폰 위치 서비스를 켜고 앱에 **정확한 위치**를 허용하세요. 음성 입력에는 마이크 권한과 기기 음성 인식 서비스가 필요합니다. APK는 아이폰에 설치할 수 없습니다. 팀 서명 제출본 `apk/`는 변경하지 않았습니다.

## 이번 수정

- 지도: 추천순(이용 가능 여부 → 가까운 순)으로 여러 장소를 스크롤합니다. 실시간 이용자 평점 순위가 아닙니다. 실제 검색은 분류별 최대 15곳, 예시는 분류별 4곳입니다. 실제 장소와 예시를 구분합니다.
- 휴대폰: 지도·추천 목록·펼친 상세 버튼을 하나의 목록에서 스크롤합니다. 차량 가로 화면은 지도와 목록의 나란한 배치를 유지합니다.
- 사진: 해당 장소에 등록된 Wikimedia Commons 사진을 저작자·라이선스와 함께 표시합니다. 사진·출처가 없거나 불러오지 못하면 분류 아이콘과 ‘등록 사진 없음’을 표시하며 다른 매장의 사진으로 대체하지 않습니다.
- 내비: 검색 결과 또는 선택한 목적지의 **현재 위치에서 안내 시작**을 누르면 정확한 GPS를 확인하고 앱 내부에서 자동차 경로를 계산해 안내합니다. 위치 권한 요청과 GPS 대기 후 연결을 포함합니다. 목적지 접근 거리가 큰 경우 기존 확인 절차를 유지합니다.
- 음성: ‘판교역 찾아 줘’, ‘판교역으로 안내해 줘’, ‘판교역까지 데려다줘’로 내비 화면을 열어 검색합니다. 동명이 있을 수 있으므로 주소를 확인하고 ‘1번’ 등 결과 번호를 말하면 해당 목적지로 안내합니다. 검색어를 화면에도 반영합니다.
- 검색: 최신 GPS가 있을 때 주변을 우선하되 국가를 제한하지 않습니다. GPS가 없으면 전 세계 검색 결과일 수 있으므로 주소를 확인해야 합니다.

## 검증과 제한

core 149개 + Android 161개, 총 **310개 통과·실패 0·건너뜀 0**. 공식 SDK 포함 lint·phonePreview APK 빌드가 통과했습니다. [이번 수정의 검증 기록](runtime-fixes-verification.json)을 참고하세요. Robolectric 화면·위치·음성 콜백 검사는 실제 삼성 S20+의 마이크·GPS·스피커 시험을 뜻하지 않습니다. 공식 SDK를 포함해 컴파일했으며 공식 Pleos 기기 전체 시나리오 검증을 새로 수행한 것은 아닙니다.

이번 실제 HTTP 점검에서 Wikimedia Commons 메타데이터와 썸네일은 HTTP 200으로 응답했지만 Overpass 장소 검색은 20초 후 시간 초과했습니다. 등록 사진이 없는 매장과 공개 서버 장애·지도 데이터 누락은 남은 제한입니다. 장소 수와 모든 매장의 사진을 보장하지 않습니다. 상용 장소 API 키는 설정되어 있지 않습니다.

기존 배경 소리·화이트/블랙 등 테마는 유지됩니다. 실제 교통·차선 안내는 제공하지 않습니다. 차량 기기에서는 정차 전용 정책을 유지합니다.
