# CabinOS ONE 휴대폰 검토본

퓨처랩스 · Android 10 이상. 차량용 화면 크기와 안전 잠금은 유지하며 휴대폰에서는 기존 반응형 화면을 사용합니다. 삼성 S20+ 사용 의견을 반영한 검토본이며 삼성 실물·아이폰·공식 Pleos 실기 검증 완료를 뜻하지 않습니다.

- 앱: **CabinOS ONE 테스트** (`io.cabinos.one.preview`, `0.11.1-preview`)
- APK: [퓨처랩스_CabinOS_ONE_preview.apk](퓨처랩스_CabinOS_ONE_preview.apk) · [SHA-256](SHA256SUMS)
- 기존 검토본 위에 업데이트할 수 있으며, 원래 차량용 앱과 별도로 설치됩니다.
- 최적화된 테스트 서명 APK입니다. 팀 서명 제출본 `apk/`는 변경하지 않았습니다.

## 수정 사항

실제 OSM 도로·건물·장소 지도, 지형 색 보존, 분류별 주변 검색, 앱 내부 목적지 연결, GPS 수신 후 경로 계산, 배경음 신호·미디어 음량 안내, 큰 소리 선택 창, 음성 세션 제어, 화이트·블랙 포함 10개 테마를 반영했습니다.

## 설치와 검토

APK를 내려받아 설치하세요. 설치 과정에서 요청될 때 다운로드한 브라우저의 앱 설치를 허용할 수 있습니다. 위치 기능은 휴대폰 위치 서비스와 앱의 정확한 위치 권한이 필요합니다. 실내에서는 GPS 수신이 늦거나 불가능할 수 있습니다.

집중 세션 → **배경 소리 선택** → 소리를 누르세요. 안 들리면 **휴대폰 미디어 음량**과 블루투스 출력 기기를 확인하세요. 음성 입력과 읽기는 기기 음성 서비스·언어팩에 따라 지원 범위가 다릅니다.

지도 → 위치/기준점 선택 → 분류 또는 주변 검색 → 장소 → **앱에서 길 안내**를 사용하세요. 자동차 경로이며 도보 예상과 다릅니다. 실제 교통·차선 안내는 제공하지 않습니다. 지도 제공 데이터에 없는 건물·가게까지 완전하게 표시한다고 보장하지 않습니다.

휴대폰의 차량 신호는 데모 데이터입니다. GPS 미확인 상태의 판교역 지도는 명시된 예시 위치입니다. APK는 아이폰에 설치할 수 없습니다. 웹 검토본은 별도이며 실제 iPhone 재생은 미검증입니다.

## 검증

core 146 + Android 156 = **302개 통과, 실패 0**. 공식 SDK 포함 phonePreview 빌드·lint 통과. 실제 OSM 타일을 받은 Android Compose 화면에서 판교역 주변 도로·건물명을 확인했습니다. 동일 SHA-256 APK를 Android 13·15 일반 에뮬레이터에서 실행해 각각 11개 검사를 통과했습니다. 지도 로딩, 세 배경음의 재생 상태, 안전 잠금, 색상 설정과 세로 화면을 포함합니다.
