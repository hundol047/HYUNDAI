# 교통 중계 서버 준비본

계정 생성·호스팅 구매·공개 배포를 하지 않았습니다. Python 3 표준 라이브러리로 실행합니다.

- `TOMTOM_SERVER_API_KEY`: 실제 공급자 키. 서버 환경변수로만 제공.
- `CABIN_TRAFFIC_TOKEN`: 별도의 무작위 24자 이상 접근 토큰. 공급자 키와 다른 값.
- `CABIN_TRAFFIC_REQUEST_BUDGET`: 프로세스당 공급자 요청 상한(기본 100). 재시작하면 초기화되므로 상용 과금 방지 장치는 아님.
- `CABIN_TRAFFIC_PORT`: 기본 8010. 서버는 127.0.0.1에만 바인딩.

```sh
python3 -m unittest discover -s server -v
python3 server/traffic_gateway.py
```

앱은 정차 중 ‘교통 연결’에서 HTTPS 중계 주소와 접근 토큰을 입력합니다. 설정은 메모리에만 보관하고 공급자 키는 APK에 넣지 않습니다. HTTPS 배포 시 운영자가 유효한 인증서·사용자 인증·사용량 제한을 구성해야 합니다. URL/인증 헤더 로깅을 끄고 응답을 외부 CDN에 캐시하지 마세요.

## 현재 범위

- `/flow?point=위도,경도`: 현재 위치 인근 1개 도로 구간. 모든 도로 조회·방향/차선 매칭·사고 원인·교통 반영 ETA/우회 경로는 제공하지 않음.
- 앱은 최신 GPS가 있을 때 최대 60초에 한 번 요청하며 조회 후 90초가 지나면 제거합니다. `fetchedAtMs`는 공급자 관측 시각이 아닌 서버 조회 시각입니다.
- 평상시 속도 대비 50% 이하=정체(빨강), 80% 이하=서행(노랑), 초과=원활(초록). 폐쇄=빨강, 신뢰도 0.7 미만=회색. 이 기준은 앱의 시험용 분류이며 TomTom 공식 정체 등급을 의미하지 않습니다.
- 한국 국내 서버 조건을 확인하지 않았으므로 위도 32–40/경도 124–132 범위와 그 범위가 포함된 응답은 거절합니다. 이 차단을 없애려면 국내 처리·보관·표시 조건부터 검토해야 합니다.
- 30초 메모리 캐시, 공급자 호출 간격 2초, 동시 요청 거절, 응답 크기·좌표·숫자 검증. 실패는 ‘정보 없음’으로 표시하며 녹색으로 대체하지 않습니다.
- 앱 백그라운드 이동 시 작업 취소, 정차 안전 판정은 변경하지 않습니다.

## 검증

공개 암스테르담 시험 좌표를 로컬 중계 서버로 요청해 HTTP 200, 도로 형상 102점과 속도 정보를 받았습니다. 인증 없는 요청 401, 한국 좌표 요청 400, 공급자 호출은 해외 요청 1회만 발생했습니다. 휴대폰 설치본의 실서버 연결·한국 교통·실차 검증이 아닙니다.
