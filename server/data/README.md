# 한국도로교통공단 사고 다발지역 참고 자료

출처: 한국도로교통공단 교통사고정보 개방시스템 https://opendata.koroad.or.kr/ . 사용자가 공식 CSV 다운로드 기능으로 받은 `10_25_stt.zip`, `17_25_lg.zip`에서 가공했습니다. 다운로드 확인·가공일: 2026-10-26.

연도 근거: https://opendata.koroad.or.kr/api/down/accidenthazard_codelist_down.jsp 의 공식 코드표에서 통계 기간과 `사고다발지id`의 대응 관계를 직접 확인했습니다. `koroad-periods.json`은 이 대응표와 원본 SHA-256만 보관합니다. 원본 XLSX의 개인 작성자·로컬 파일경로 등 부수 메타데이터는 배포하지 않습니다.

| 유형 | 실제 통계 기간 | 선택 ID | 구역 수 |
|---|---|---|---:|
| 지자체별 | 2025 | 2026134 | 683 |
| 보행자 | 2023–2025 | 2026122 | 418 |
| 보행어린이 | 2025 | 2026124 | 88 |
| 결빙 | 2021–2025 | 2026125 | 82 |

총 1,271개 구역. 보행어린이는 어린이보호구역 전용 자료가 아닙니다. 결빙은 과거 결빙 사고 이력이며 현재 결빙 감지 정보가 아닙니다. 유형별로 최신 공개 통계 기간을 선택해 과거 기간 9,093행을 현재 안내에서 제외했습니다. 같은 장소의 서로 다른 유형은 통합해 사고 건수를 더하지 않습니다. 최신 데이터 안의 동일 FID 중복은 0건입니다.

전체 10,364행의 좌표 범위와 경계를 검사했습니다. 과거 보행어린이 자료의 MultiPolygon 58개도 유효하며 최신 기간 선택에서 제외된 것이지 형식 오류로 누락한 것이 아닙니다. 최신 선택 구역은 모두 Polygon입니다. 변환기·서버·앱은 MultiPolygon과 내부 구멍도 처리합니다. 좌표 없는 지역별 통계 파일은 지점 안내에서 제외합니다.

`accident-zones.json`은 원래의 위도·경도 및 경계를 유지합니다. `year`는 호환성을 위한 통계 종료 연도이고, 실제 안내는 `periodStart`–`periodEnd`를 사용합니다. 검토 유효기한은 **2026-12-28 00:00 UTC**이며 그 이후에는 역사 자료를 안내에서 제외합니다. 이는 통계 연도가 바뀐다는 의미가 아닙니다. 재검토·새 자료로 갱신해야 합니다.

재현 명령(원본 ZIP은 별도 보관):

```bash
python3 scripts/import_accident_archives.py /path/10_25_stt.zip /path/17_25_lg.zip --periods server/data/koroad-periods.json --expires-ms 1798416000000 --output server/data/accident-zones.json --audit server/data/accident-zones-audit.json
```

공공 통계 위치·구역의 현실 정확성, 모든 사고·위험 지역의 포함 여부, 고가도로/지하도로 높이 차이와 통행 방향을 보장하지 않습니다. 구역 경계와 예정 경로의 2차원 교차를 참고 안내하며 실시간 사고 확정·현재 도로 통제·결빙 상태로 표현하지 않습니다.
