실제 Compose UI를 Robolectric 네이티브 그래픽 모드에서 렌더링한 이미지입니다. 실차 캡처가 아닙니다. 지도 이미지는 오프라인 UI 검사 결과로 타일을 포함하지 않습니다. 글로벌 내비 이미지는 합성 경로·GPS로 검사한 Compose 화면입니다.

01

설치하고 실행하기

Android 10(API 29) 이상에서 APK를 다운로드해 설치하세요. 필요하면 브라우저의 앱 설치 권한을 허용해 주세요.

02

함께 작동하는 세 서비스

주행 중 EchoRoad, 안전한 주차 확인 후 StopSense와 CabinOS가 동시에 작동합니다. 왼쪽 데모 메뉴에서 상태를 바꿀 수 있습니다.

03

지원 범위를 확인하세요

지도는 OpenStreetMap, 장소는 명시적 주변 검색으로 불러옵니다. Pleos 실차 SDK·실제 충전 데이터는 미연동입니다. Android 기기 음성 서비스와 언어팩이 필요하며 최종 실차 실행 검증은 남아 있습니다.
